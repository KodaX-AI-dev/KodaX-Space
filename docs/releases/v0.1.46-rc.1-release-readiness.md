# v0.1.46-rc.1 release readiness

Date: 2026-09-17. Previous release: v0.1.46-beta.5. First release candidate of the
0.1.46 line.

## Scope

- Pin the exact published KodaX `0.7.96-rc.8` in root/Desktop manifests and the lockfile
  (`sha512-eDAxYhXo7V4jVrNXJ4OxszsAkqynrPVZt/bnH8z71rsH0k5vUXqFN4EGFs+vuc8ELk4wHECV+OLBBwjwEJOWnQ==`,
  byte-identical to the published GitHub release tarball), superseding rc.7. Every rc.7
  capability contract is retained (`sandboxRuntime:11`, `runtimeAutoModeGuardrail:6`,
  `sharedSessionSettings:2`, `providerCredentialBroker:2`, `effectiveConfig:1`, daemon
  `sessionCancellation:1` with durable frontier, `toolInvocation:1`): no Space capability
  gate moves.
- Reasoning effort becomes intent-preserved with SDK-owned negotiation: chat requests,
  shared Runtime settings and workflow launches keep the user's selected intent; the SDK
  owns effort fallback and per-provider/model rejection caching. Unknown OpenAI-compatible
  capability profiles may attempt Off, auto and every standard effort level — unknown
  capability is distinct from declared lack of support. The SDK's `reasoning_resolved`
  observation is forwarded through daemon and embedded host paths (root observations are
  not replaced by transient child observations) as a typed session event; the model picker
  separately reports the last sent effort and typed fallback reasons, scoped to the current
  provider/model/intent. Success responses and absent visible thinking are never presented
  as proof that an effort strength took effect. The SDK compatibility layer keeps parsing
  and replaying `reasoning_content`, `reasoning`, and structured `reasoning_details`; Space
  adds no second wire parser.
- Error classification recognizes native and cause-wrapped TimeoutError/AbortError,
  including numeric DOMException codes and cyclic cause chains, without crashing.
- Local HTML animation previews allow nested pages from the same preview directory in both
  network modes (`frame-src 'self'`), fixing blank iframe-based animation players; remote
  frames remain blocked and local file access stays capability-scoped.
- Synchronize workspace versions, changelog, READMEs, capability ledger, product/
  architecture/usage docs, user manual, feature list, `docs/features/v0.1.46.md`,
  kodax_manual (rc.1/rc.8 stamp with anchored contract test), and add the
  [rc.8 reasoning regression guide](../test-guides/ISSUE_REASONING_0.7.96-rc.8_REGRESSION_GUIDE.md)
  plus the [reasoning research note](../research/openai-compatible-reasoning-extensions.md).

## Qualification

- Typecheck and lint pass; the focused unit suites cover reasoning intent projection,
  unknown versus declared capability, daemon event provenance, workflow intent, typed
  error recognition and installed Runtime contracts.
- Live provider qualification (recorded in the regression guide): real OpenRouter runs
  over the released rc.8 package on an unprofiled compatible provider — the effort matrix
  (default auto sent max; none/low/medium/high/xhigh/max sent as selected; 8/8 cases),
  an invalid-effort round that fell back to max and skipped the cached rejection on the
  next round, and a `gpt-oss-20b` round trip that returned and replayed structured
  `reasoning_details`. Credentials stayed out of logs; synthetic reports contain no
  headers or secrets.
- The manual-topics contract pins the rc.1/rc.8 phrasing.

## Remaining boundaries

The effective strength of a reasoning effort remains unverifiable from the wire alone:
the picker states facts (what was sent, why something fell back) and never claims an
effect. Pure configuration-type extension commands remain CLI-owner-only. Partner Coder
sharing of experts/connectors, real external-account acceptance, and automatic library
replacement for the bundled Partner library remain open items from earlier readiness
records. FEATURE_275 long-term guarantees are unchanged.
