## 静态构图与单次运动

主角是局部玻璃任务切换面板，底部输入框为第二层；后方工作面和静止暖光提供可透出的内容。前景文字保持清楚。没有图片素材需求，沿用实际项目字体、图标与 K 标识。

| 状态 | 主角与构图                             | 运动                                       | 时长                        | 结束帧                   |
| ---- | -------------------------------------- | ------------------------------------------ | --------------------------- | ------------------------ |
| 打开 | 玻璃任务面位于工作面前，输入框固定底部 | 轻微上移与展开，扫光一次；不动画 blur 半径 | 展开 380ms / 扫光 850ms     | 面板稳定、边缘清楚       |
| 切换 | 同一前景面板内的三条任务               | 一块选中底板连续移动，更新后景任务         | 380ms，每次动作间隔约 800ms | 当前项目与选中任务一致   |
| 成果 | 操作面收起，工作内容恢复完整           | 成果短距离揭示，输入框光扫一次             | 500 / 850ms                 | 文本和成果固定           |
| 静止 | 连续画布与局部玻璃输入框               | 无循环；可再次手动播放                     | 整段 4.5s 后结束            | 可继续操作任务与材质对照 |

材质三档是现有视觉质量概念的样稿对照，不是新的三种布局或主题：极简为实色、无 backdrop blur；均衡使用局部 CSS 玻璃；全特效增加通透与景深，不加入持续流体计算。主题 Light / Dark / System 仍由顶部控制；减少动态效果保留静态材质和状态反馈。
