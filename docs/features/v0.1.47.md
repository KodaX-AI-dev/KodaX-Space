## 接入落点

- 启动仍用 ensure、重连用 passive connect，按真实能力版本拒绝不兼容 Host；启动要求 `sandboxRuntime:11`、`runtimeAutoModeGuardrail:6`、`sharedSessionSettings:2`、`effectiveConfig:1`，daemon 准入另需 `providerCredentialBroker:2`，打包依赖 smoke 要求 `conversationHistory:2`、`crashOutcomeModel:2` 与 alpha.3 生命周期契约（`daemonOrphanExit:1`、`actorSettlementConvergence:2`、`daemonShutdownVerification:1`、`productClient:1`）。
- 普通输入走 `acceptInput`，显式工具走带 inputId 与 authorization 的工具入口；技能、命令 hooks 与 review 的准备由 Host 完成，Partner 保留自己的 inline 执行边界。
- 重连从 SDK 当前 view/snapshot 重建（不再有 journal/replay）；长 view 正文校验长度、revision、offset 与读取期限，过期 canonical 边界拒绝。
- Space 手册经现有只读 Host Tool `space_manual` 组合安装 SDK 手册与 Space 操作说明；发布 SDK 拒绝覆盖内建 `kodax_manual`。
- Stop 后新输入 admission 期间的观察订阅不再过早退役（stop-then-send 保持 Session observer 附着，live 输出照常到达）。

## FEATURE_147: Integrated Workspace and Full Settings Surface

### 需求概述

2026-10-16 用户批准融合原型进入正式产品。以连续画布、分栏、局部玻璃与克制动效统一工作区和设置，默认保留全部既有能力、多项目并行、深浅/系统主题与三档视觉质量。任何功能删除先另行对齐。此项为当前源代码后续改进，不修改既有发布声明或版本号，不关闭 F139 的独立剩余范围。

### 影响范围

Renderer Shell、左右侧栏、SurfaceTabs、BottomBar 外壳、Partner 外壳、设置容器/appearance、共享 styles 与相关 E2E。完整保留映射见 [功能清单](../design/space-ui-integration.md)。

### 技术方案

复用真实 React 组件及状态源；CSS tokens 与局部材质负责视觉，设置作为 Shell 内工作面，后台工作区保持挂载并隐藏/inert；所有设置入口统一，保留嵌套确认的焦点与 Escape 优先级。原 Artifact/Diff/专注能力承接 B/C，不创建第二个执行模型。无新增第三方依赖。

### 接口契约

SDK/IPC/持久化合同不变。主题与视觉质量继续用既有 appStore 和 localStorage；设置 tab ID、六分类、语义控制 broker 不变。设置从遮罩对话框改为命名 region，关闭/返回和 Escape 保留，背景单击关闭随遮罩消失由页面导航替代。

### 实现步骤

1. 记录逐项功能映射；E2E 先验证设置工作面、草稿保持、全部主题/质量和定向打开（RED）。
2. 实施连续 Shell、共享分栏及统一材质，保留所有组件与 handler。
3. 设置页面化，复用全部设置子面板，添加共享 appearance 入口。
4. 运行回归、类型/静态检查与构建；实际深浅截图与三档/性能验证；Standards + Spec 评审。

### 验收标准

- 功能清单中的原能力均有入口，无未对齐删除。
- 工作区/设置统一视觉，多项目工作状态继续可见，切换设置不丢输入草稿或停止运行。
- 深浅/系统主题与三档质量在标题栏、菜单、设置之间同步并持久化。
- 设置六分类/编辑、Provider 错误恢复、键盘、嵌套确认、关闭返回均可用。
- 流式/历史/后台效果降载与 reduced-motion 保留；无新动画运行时依赖。
