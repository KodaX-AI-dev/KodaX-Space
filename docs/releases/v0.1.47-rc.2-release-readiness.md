# v0.1.47-rc.2 release qualification

日期：2026-11-24。用户指定 Space `0.1.47-rc.2` 预发布；SDK 为 npm Registry `@kodax-ai/kodax@0.7.97-rc.2`（自 rc.1 的 rc.1 升级），四个 workspace 与 lockfile 统一 Space 版本。稳定版保持 v0.1.46，不向正式版自动推送预发布。已发布的 rc.1（SDK rc.1 构建）及更早 beta/alpha 记录保留为上一轮发布历史。

## 发布范围

- SDK `0.7.97-rc.2` 接入（RepoIntel phase 0）：默认 `auto` 模式只提供基于 git 的 `repo_overview` / `changed_scope` / `changed_diff`；语义工具、注入的模块/影响上下文与索引预热需要 `repoIntelligenceMode` `full` / `light`。索引从工作区 `.agent/repo-intelligence/` 移到 `<config home>/repo-intelligence/`。切换模型不再把上一个模型的思考写进回复（SDK Issue 441），Gemini 把他模型的工具调用重放为真实调用（SDK Issue 442）；`zhipu-coding` 新增 `glm-5.4`，回退上下文上限按 1M 对齐。
- Repointel 芯片：许可证有效且处于 `auto` 时显示绿点 “Git”，不再显示 “idle”；`/repointel` 与芯片弹窗说明 git 工具已开启、语义索引需显式开启，不再提示“已被 Host 设置禁用”。`repointel.status` 输出新增 `configuredMode`。
- 时间线标记：压缩、切换模型与简短的运行状态提示显示为居中于细线的胶囊，不再是通用卡片。`/compact` 显示压缩前后 Token（如 142k → 31.4k）、保留比例与缩减百分比；`/model` 与模型选择器显示前后模型（仅跨 Provider 时带 Provider 名）。连续切换合并为一个标记，切回原模型不显示，第一轮之前的切换不显示。标记随本地通知保存并从历史恢复，纯文本仍可复制与查找。
- 进行中文字扫光：活动状态、实时思考与运行中的工具组标签带扫光；压缩进行中，运行末尾在标记落点显示实时胶囊，代替 Run 标记。极简视觉质量与系统减弱动效下关闭。
- 消息操作栏：复制 / fork / 回退与时间在鼠标悬停整条消息或键盘聚焦到其按钮时显示，最新一条回复常显；悬停只展开指针所在的标签，时间不位移。
- 待确认 Stop：当前 Session 的待确认 Stop 记录在其 Run 被界面或 Host 报告为终态后自动清除，重启后不再为已结束的 Run 显示“重试停止”。
- 应用内 `space_manual` 改写为当前产品参考：去掉版本与 Issue 历史，修正过期事实（RepoIntel 模式、模型与服务商入口、内置终端不继承 `KODAX_HOME`、MCP 由共享 Host 管理、Smart Popout 聚焦 Task Dock 分区、Repointel 芯片位置与预热条件、Stop 重试入口的清除时机）。SDK 自有 `kodax_manual` 不被覆盖，同名主题仍动态附上安装 SDK 的原始正文。
- 当前 README、文档索引、Feature List、版本设计、DD、USAGE、PRD、用户手册、已知问题与能力台账随 rc.2 更新；Issue 255 标记为已在 0.1.47-rc.1 发布。

## 验证与发布门

- 本地 Windows 完整源码检查在发布准备提交后的最终树上执行：typecheck、lint（`--max-warnings 0`）通过；`npm run test:release` 通过（162 项：154 通过、7 跳过、1 todo、0 失败）；workspace 单测 0 失败（desktop electron/renderer 4587 项：4565 通过、22 跳过；ipc-schema 380 项全部通过）。
- 发布需同一 SHA 的四平台完整源码检查（ci.yml E2E 双分片 + build.yml 四平台 smoke、静态检查与门禁）、成品构建和成品消费验收。Mac arm64/Intel 在候选归档前通过 `codesign --verify --deep --strict`；Windows 打包 smoke 继续校验 SDK 原生资源哈希与内置 Skill 解包完整性。
- 最终 SHA、运行链接、平台结果与资产校验记录在发布后补记的验证文档（`v0.1.47-rc.2-release-verification.md`）。该记录未确认的项目不得以源码通过替代。

## 保留边界

- macOS ad-hoc 不等于 Developer ID 或公证，首次启动仍可能有 Gatekeeper 提示；通知/图标角标需要系统权限，macOS 仍手动下载 DMG 更新。Windows 安装器未签名。
- Issue 371 首次历史读取延迟仍未关闭，Issue 254（Run 期间历史翻页重复/乱序）推迟到下一大版本；默认 `auto` 不建语义索引，Full / Light 模式的首次路由耗时（Issue 213）未在 rc.2 重新测量；SDK Repo-intelligence Host 真实诊断/预热等接缝沿用既有验收记录，不因本版重开或宣称消失。
- 外部账号、真实模型质量/计费、覆盖安装/断电、客户 Kylin/真实 Mac 权限设置仍需对应环境验收。
