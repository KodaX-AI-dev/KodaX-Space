# v0.1.47-alpha.5 release qualification

日期：2026-11-09。用户指定 Space `0.1.47-alpha.5` 预发布；精确依赖 npm Registry `@kodax-ai/kodax@0.7.97-beta.4`，四个 workspace 与 lockfile 统一 Space 版本。稳定版保持 v0.1.46，不向正式版自动推送 alpha。已发布的 alpha.4（beta.1 构建）记录保留为上一轮发布历史。

## 发布范围

- SDK beta.1 → beta.4 接入，见 [beta.4 适配](kodax-beta4-space-adaptation.md)、[beta.3 适配与验收](kodax-beta3-space-adaptation.md)与[beta.2 适配](kodax-beta2-space-adaptation.md)。历史契约 v2：Fork/Rewind 提交 SDK 解析的完整轮次，过期目标返回类型化 `resync_required` 原因，活动工作报 busy，不完整轮次有明确解释，更新保存页跟随 SDK `newerCursor`；Space 要求 Host 提供历史定位与轮次解析 v2。
- 规则来源分离：SDK beta.4 将 `~/.kodax/rules/*.md` 与项目 `.kodax/rules/*.md` 注入 Host 提示词；AGENTS.md 编辑绑定 Main 确认的精确原路径，不再出现 `.kodax/AGENTS.md` 覆盖根文件的问题。打包核验 Windows containment 程序资源。
- 新会话工作模式默认值：成功的模式变更保存到 Space 运行时默认，新对话预览与 Host 草稿创建使用保存的模式；已有 Session、Partner Agent 模式与临时 Quick Ask 不受影响（Issue 220 指引已更新）。
- 成果文件操作：注册为 file Artifact 的 workspace HTML/HTM 复用隔离的项目 Web 预览；经项目校验的 workspace 文件支持另存为；卡片、面板与独立窗口提供共享的另存为/显示/复制操作，动作绑定选中版本，原有导出策略与审计不变（[F059 指引](../test-guides/FEATURE_059_v0.1.47_TEST_GUIDE.md)）。
- 历史浏览与阅读体验：同一修订内已读保存页连续保留，双向浏览不重复取页，底部动作回到实时输出；用户提问带本地化发送者标签、浅蓝背景与左侧强调边；程序化搜索定位不触发相邻翻页，原生滚动条拖拽在慢渲染与页面尺寸变化下保持方向。
- Composer：Lexical 编辑器原子 command/skill/file 补全标签、浅色行内引用样式与有限聚焦反馈；命令回执以持久 Space 收据为唯一来源，不再出现重复命令气泡。
- 设置分组直达导航：应用/任务/能力/系统四组十项加关于页；MCP、技能、外部 Agent 独立可见，压缩与 Workflow 限制同页，健康/迁移/诊断归排障；页面首访挂载，本次打开期间保留草稿，旧六分类入口在边界映射。
- 其他：MCP OAuth 打开前验证本地 HTTP 就绪并重绑浏览器受限端口；遗留排队输入经 principal 绑定幂等撤回回执恢复；Workflow 呈现为显式单次执行并退役管理操作；repo intelligence 在执行 Host 检查与预热；可用时向 SDK Artifact 工具提供已安装的 LibreOffice 控制台转换器。
- 当前 README、文档索引、PRD/HLD/DD、能力/凭据台账、用户手册、版本设计、内置技能记录与应用内 `space_manual` 同步 alpha.5 / beta.4 基线，settings/agent-modes/artifacts 手册主题按新交互更新。SDK 自有 `kodax_manual` 不被覆盖。

- 修复层完整本地 `npm test` 通过（0 失败，含平台/条件跳过），typecheck、lint、Main/renderer 生产构建通过。beta.4 历史契约 v2、缩放桌面真实 SDK 历史强调、连续保存页、原生拖拽边界、命令回执去重、artifact IPC 与浏览器回归均有定向覆盖。

- 最终 SHA、运行链接、平台结果与资产校验记录在 [本版发布验证](../research/v0.1.47-alpha.5-release-verification.md)。该记录未确认的项目不得以源码通过替代。

## 保留边界

- macOS ad-hoc 不等于 Developer ID 或公证，首次启动仍可能有 Gatekeeper 提示；通知/图标角标需要系统权限，macOS 仍手动下载 DMG 更新。Windows 安装器未签名。
- SDK Repo-intelligence Host 真实诊断/预热、integration writer 短暂占用恢复等接缝沿用 [beta.1 完整验收](kodax-beta1-full-acceptance.md)与 beta.2/beta.3 记录；不因升级宣称已消失。
- Issue 371 首次历史读取延迟仍未关闭，Host ready 不等于历史加载完成。不因升级宣称所有恢复性能或智能质量问题已解决。
- 外部账号、真实模型质量/计费、覆盖安装/断电、客户 Kylin/真实 Mac 权限设置仍需对应环境验收。
