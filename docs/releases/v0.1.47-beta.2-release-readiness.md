# v0.1.47-beta.2 release qualification

日期：2026-11-17。用户指定 Space `0.1.47-beta.2` 预发布；精确依赖 npm Registry `@kodax-ai/kodax@0.7.97-beta.11`（`sha512-RDI+PRx3RjvmelfIDvewzRMFSg06WBDpTGGEu4/q9lzCsPDb0W3KjLMXUndtiT4RY7uEvjVgzKY1CTswtYoVow==`），四个 workspace 与 lockfile 统一 Space 版本。稳定版保持 v0.1.46，不向正式版自动推送预发布。已发布的 beta.1（beta.10 构建）与 alpha.4/alpha.5 记录保留为上一轮发布历史。

## 发布范围

- SDK beta.11 精确固定（root/Desktop/lockfile 同一 Registry tarball）：失败 Run 的错误保留在对话中，下一次发送与重开 Session 后仍在原位置，CLI 的 "Recovery exhausted. Type continue…" 提示不再出现（Issue 252 收口）；历史页从 revision log 读取，Run 写入不再使其失效，读被活跃写入者跨越时 SDK 返回 `resync_required` 与 `data.reason: 'writer_active'`，Host 重试一次；多问题提问部分作答以 `unanswered` 上报给模型；同一 ask 内重复问题文本被拒绝；Skill `allowed-tools` 被忽略（以 Host 权限模式为准）；内置 Skill 解析到 `app.asar.unpacked`。
- Windows 上注册 Space 内置 Skill 扩展可等待占用 `extensions.json` 的扫描器约 1.6 秒（退避 25–800 ms），不再约 150 ms 后放弃导致该 Run 缺少内置 Skills；仅失败路径等待，警告带系统错误码。
- 打包版内置 Skill 脚本可 `import` `yaml` 与 `fflate`：两者从 `app.asar` 解包；打包 smoke 在内置 Skill 脚本 import 的包缺失于 `app.asar.unpacked` 时失败（`smoke-pack-builtin-imports.test.mjs` 覆盖）。
- 被截断的工具表头仍显示文件路径或桥接工具名；截断的 `create_artifact` 卡按 id 打开已存 Artifact，而不是用残缺内容构建快照。
- Run 工作期间浏览旧历史不再卡在 "history changed"：后台刷新失败保留已加载旧页边界，"Return to latest" 立即切回实时视图，30 秒/窗口聚焦的最新页刷新等 Run 结束，Host 对 `writer_active` 重试一次；工具组 token 计数在 Run 裁剪旧正文时不再回缩。
- Run spinner 回到对话流末尾，不再固定在输入框上方；comet 换成 KodaX Run 标记（点阵方块翻滚后压平成像素 K）。Run 期间上翻历史时，“返回最新消息”按钮带上标记、已用时间和运行中子 Agent 数。所有标记共用一个 rAF 循环，离屏、窗口隐藏或无 Run 时停止；减少动效与极简档显示静止的 K。设计记录见 [run-mark](../design/run-mark/direction-approved.md)。
- 当前 README、文档索引、PRD/HLD/DD、USAGE、能力/凭据台账、Feature List、内置技能记录、Known Issues 与应用内 `space_manual` 同步 beta.11 / beta.2 基线；Issue 252 状态更新为 Resolved in 0.1.47-beta.2。SDK 自有 `kodax_manual` 不被覆盖。

- 本地 Windows 完整源码检查：typecheck、lint（`--max-warnings 0`）、workspace 单测（desktop electron/renderer、ipc-schema）与 `npm run test:release`（含 `skills:check`、原生资源预热与 `scripts/test/*.test.mjs`，其中 builtin-imports 冒烟覆盖解包依赖）全部通过。
- 发布需同一 SHA 的四平台完整源码检查（ci.yml E2E 双分片 + build.yml 四平台 smoke、静态检查与门禁）、成品构建和成品消费验收。Mac arm64/Intel 在候选归档前通过 `codesign --verify --deep --strict`；Windows 打包 smoke 继续校验 SDK 原生资源哈希与内置 Skill 解包完整性。
- 最终 SHA、运行链接、平台结果与资产校验记录在 [本版发布验证](v0.1.47-beta.2-release-verification.md)（发布后补记）。该记录未确认的项目不得以源码通过替代。

## 保留边界

- macOS ad-hoc 不等于 Developer ID 或公证，首次启动仍可能有 Gatekeeper 提示；通知/图标角标需要系统权限，macOS 仍手动下载 DMG 更新。Windows 安装器未签名。
- SDK Repo-intelligence Host 真实诊断/预热等接缝沿用 [beta.1 完整验收](kodax-beta1-full-acceptance.md)与 beta.2/beta.3/beta.8/beta.9 记录；不因升级宣称已消失。
- Issue 371 首次历史读取延迟仍未关闭，Host ready 不等于历史加载完成。不因升级宣称所有恢复性能或智能质量问题已解决。
- 外部账号、真实模型质量/计费、覆盖安装/断电、客户 Kylin/真实 Mac 权限设置仍需对应环境验收。
