# Partner Architecture Decision Records

本目录只记录 Partner 产品线内部、需要长期保留理由与取舍的架构决策。

影响 Space Runtime、Coder、共享 IPC、安全基线或发布契约的决策必须继续写入全局 [`docs/ADR/`](../../ADR/)，不能迁入本目录。Partner 是同一 KodaX Runtime 上的 Space surface 这一根本决策仍以 [ADR-007](../../ADR/ADR-007-partner-surface-model.md) 为准。

当前没有需要从全局 ADR 迁入的 Partner 私有决策。出现真实决策时采用 `P-ADR-001-<slug>.md` 编号，并至少记录状态、上下文、决策、替代方案、后果以及对 Space 集成的影响。
