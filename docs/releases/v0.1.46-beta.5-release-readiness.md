# v0.1.46-beta.5 release readiness

Date: 2026-09-16. Previous release: v0.1.46-beta.4.

## Scope

- Pin the exact published KodaX `0.7.96-rc.7` in root/Desktop manifests and the lockfile,
  superseding rc.6. rc.7 returns eligible file outputs from successful writes over A2A in
  both coding and managed execution — independently of conversation compaction and the
  memory artifact ledger — and recognizes HTML/HTM outputs as `text/html`. Every rc.6
  capability contract is retained (`sandboxRuntime:11`, `runtimeAutoModeGuardrail:6`,
  `sharedSessionSettings:2`, `providerCredentialBroker:2`, `effectiveConfig:1`, daemon
  `sessionCancellation:1` with durable frontier, `toolInvocation:1`): no Space capability
  gate moves and the existing bounded artifact projection is unchanged.
- Synchronize workspace versions, changelog, READMEs, capability ledger, product/
  architecture/usage docs, user manual, feature list (including correcting the beta.4 row,
  which shipped rc.6 rather than the rc.5 written during its preparation),
  `docs/features/v0.1.46.md`, and kodax_manual.

## Qualification

Typecheck and lint pass; the full unit suites (release-gate scripts with the rc.7
compatibility gate, the desktop suite, and the ipc-schema workspace suite) pass locally
with 0 failures. The manual-topics contract pins the beta.5/rc.7 phrasing.

## Remaining boundaries

Pure configuration-type extension commands remain CLI-owner-only. Partner Coder sharing of
experts/connectors remains a follow-up. Real external-account acceptance and automatic
library replacement for the bundled Partner library remain open items from the beta.3
readiness record. FEATURE_275 long-term guarantees are unchanged from beta.2.
