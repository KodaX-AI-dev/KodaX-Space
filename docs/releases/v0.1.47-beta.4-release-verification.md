## Pre-tag repair history

main carried red `ci` before this release: the run for `4511bc52` (the composer @ folder completion commit) failed both shard-1 E2E jobs on Windows and Linux. Both failures were reproduced or attributed locally before any fix was pushed; no CI-debug-by-retry was used.

- **Stale token assertion (deterministic, 3/3 on both OS shard 1)**: `composer-tokens.spec.ts:72` still expected the inline command label to read `/help` and the skill label to equal the popover name verbatim; since `4511bc52` the reference shows the bare name (the icon carries the kind) while `aria-label` keeps the wire value. Fixed by asserting `help` plus the `/help` aria-label and stripping the `/`/`/skill:` prefix from the popover label for skills (`6945e988`); verified locally and green on both OS shard 1 afterwards.
- **Stale delete flow (deterministic, 3/3 on both OS shard 1)**: `partner-layout.spec.ts:361` right-clicked a live Partner session expecting Delete; F149 offers Delete only for archived rows. Fixed by archiving from the context menu, revealing archived sessions and deleting from the archived row, mirroring the pattern `partner-mode.spec.ts` already uses (`6945e988`).
