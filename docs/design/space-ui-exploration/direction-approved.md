# 任务伴侣动画预览方向

2026-10-17。沿用用户已经选择的融合工作区与新小狗，属于选定方向后的迭代。

用户原话：「能不能先把这套小狗做成连续动画，放进完整工作区预览里让我看看？重点看看待机、思考、工作、等待确认和完成时的动作是否自然，先不要替换正式产品。」

不重新探索三套视觉方向，不替换正式产品；只新增独立预览文件。界面、logo、字体、深浅主题、三项目会话和审阅复用 integrated.html；角色复用 companion-dog-v3 的透明原图。交付是可操作的无声工作区预览，用户原有不打扰正常工作的要求继续有效，不添加背景音乐或自动播放提示音。

## 分镜与动作卡

固定构图：左侧约 20% 项目栏、中央约 55% 连续工作区、右侧约 25% 任务详情。宠物位于项目栏底部；用户主动打开观察器后，右侧可放大同一动画。镜头不移动，不改变任务输入焦点。

| 状态     | 主角与定格     | 动作                             | 进入/停留/结束             | 检查点                         |
| -------- | -------------- | -------------------------------- | -------------------------- | ------------------------------ |
| 待机     | 坐姿，脚底固定 | 轻呼吸、低频眨眼和短摇尾         | 安静闭环，不沿整个界面漂移 | 起点、闭眼、周期衔接           |
| 思考     | 侧头坐姿       | 慢侧头、耳朵延迟跟随、轻呼吸     | 淡入后缓慢闭环             | 最大侧头与回正，不能拉裂颈部   |
| 工作     | 四足前倾       | 头部轻点、胸部呼吸、尾巴低幅动作 | 脚底固定，动作分频         | 鼻尖最低点、脚底不滑           |
| 等待确认 | 坐姿抬爪       | 抬爪后停住，少量头部/尾部变化    | 不持续挥爪，不自动批准     | 进入、抬爪保持、用户确认后离开 |
| 完成     | 坐高、开心     | 一次挺身与短摇尾，随后收住       | 完成动作单次播放，可重播   | 0.3/0.8/1.6/3 秒，不能永久庆祝 |

采用轻量 Canvas 2D 连续网格形变驱动已选透明角色，保持完整图像，不硬切身体部件；不是原九张姿态按帧轮播。大体态切换用短过渡连接；需要检查过渡时可暂停/逐帧查看。预览支持手动状态、播放一轮、速度与暂停、实际尺寸及放大观察，主题和减少动画也可操作。不同姿态底图仍存在绘制差异，过渡的残影与比例变化属于本轮重点检查对象。

## 后续评审与 v4 重做

用户否定前述微形变版本：「几乎没有任何动态，就是连续的静态帧，然后切换状态的时候有一点动态而已」「之前我就觉得原来的宠物不够顺滑，状态不够多」。本次仍属同一选定方向内的改稿，正式产品保持原样。补充真正可重叠的部件素材，改用分层骨骼、独立脚掌与连续姿态插值，动作扩展为 13 种。前述微形变段落为历史记录，当前分镜与实现边界以 `companion-rig-storyboard.md` 和 `companion-motion-study.md` 为准。

## v4 被否定，改回完整角色帧动画

用户原话：「你做成骨骼动画之后，非常非常离谱，很难看。你自己审查了吗？我觉得如果做不好，还不如帧动画。」停止骨骼方案，当前标准改为 `companion-frame-review.md`。仍是已选角色方向的改稿，不重新要求三方向选择。先做一段完整角色位图试片，未过观感自审不作为默认动画，也不批量扩展状态。正式产品与其已有功能保持原样。

## 单独精修待机

用户原话：「那就先把待机的帧动画真正做好，保持小狗造型一致，动作自然顺滑，循环不要跳。你自己仔细看过实际播放效果再给我看，还是放在完整工作区里，先不要替换正式产品。」本次仅在已选方向精修待机，不重开风格选择。采用同一造型底稿、局部眼睑原画和离线合成的完整帧；实际播放复审与素材说明见 `../assets/companion-dog-v6/README.md`。

## 按认可的待机标准扩展四个任务动作

用户原话：「这版方向可以，接下来按这个标准把思考、工作、等待确认和完成的帧动画也做好，动作要有明显区别，保持造型一致、衔接自然。你先仔细看过实际播放，再放进完整工作区让我看，先不要替换正式产品。」沿用已选角色与完整帧方案，不重开方向选择。v6待机不变；四种任务动作采用独立动作语言与预制收束路径。素材、弃用候选、实际播放与验证见 `../assets/companion-dog-v7/README.md`。正式产品不替换。
