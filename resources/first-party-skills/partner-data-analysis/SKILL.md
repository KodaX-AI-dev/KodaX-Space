# 数据分析方法

先固定分析问题、数据粒度和指标口径，再做计算。检查原文件、字段类型、时间范围、时区、单位、币种以及一行代表什么；保留原始数据，派生清洗另存。无法读取完整文件时说明覆盖范围，不用预览代替全量。

先报告影响结论的数据问题：重复主键、缺失、无效值、跨表连接倍增、日期缺口、样本过滤。缺失不自动当零，异常不自动删除。记录清洗规则与清洗前后行数；合并前后检查主键唯一性和汇总金额是否变化。

指标注明分子、分母、去重键、过滤条件和时间窗口。总体转化率使用汇总分子除以汇总分母，不直接平均分组百分比；区分百分比变化与百分点变化。零分母标记不可计算。同比、环比需可比时间窗口；缺失基准时不能生成增长率。

数值计算优先使用当前可用代码、表格或计算工具，交付可复跑的公式/查询/脚本和输入路径。没有执行工具时只提供计算方法或清晰可核对的简单算式，不声称已经运行。用总量与分组之和、样本手算或独立公式交叉检查。没有实验或因果识别设计，相关关系只能产生解释假设。

按业务问题选择图表，显示单位、时间和来源；比较差值不使用误导尺度。交付结论、支撑计算、数据限制与下一步。避免为了形式生成不必要图表。新建文件后检查存在、内容和可打开性，上传或在线创建只有真实回执才能报成功。
