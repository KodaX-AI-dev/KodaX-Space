# KodaX Space 工作区设计预览

本目录是 2026-10-16 调研、三方向初稿和多轮反馈后的交互原型。任务内容、文件差异和运行状态均为示例，未连接模型或真实工作区。

最新入口是 `index.html#integrated`：完整多项目工作区与设置页使用同一套材质和动效。字体、实际项目图标和 Lucide 图标均已内嵌，无需 CDN。

- **完整工作区**：A 的多项目导航与连续画布、B 的成果优先视图、C 的专注审阅整合为同一个工作区的不同模式。
- **播放并行场景**：两个后台示例任务陆续完成、留下未读和局部通知，人工确认保持等待，当前会话不会被自动切走。
- **设置页面**：完整设置工作面，保留六类设置；主题、视觉质感、动态偏好同步回工作区，返回后保留项目、会话、视图与草稿。
- **组件参考**：保留独立组件、材质和动效实验，作为补充，不再是主要体验入口。

具体取舍和流程见 `integrated-study.md`；验证记录见 `previews/verification-integrated.json`。

原始三方向从「看 A/B/C」进入，继续保留用于对照：

- **A · 石墨工作台（推荐）**：完整中央画布、紧凑项目导航、按需详情。
- **B · 纸白编辑室**：文档与成果优先，默认收起详情。
- **C · 专注审阅台**：紧凑导航工具带，把更多面积留给成果与审阅。

每个方向均包含明暗主题、可展开过程和局部交互。比较入口显示真实渲染截图；它用于比较设计，不属于产品界面。

此前的独立实验仍保留：

- **看布局方案**：A/B/C 为工作区结构对照，A 保留多项目分组、并行状态、会话切换与草稿。
- **试组件与动效**：单次 Agent 工作流、人工确认、成果审阅，以及可交互的按钮、列表、菜单和动效偏好。
- **玻璃与光影细化**：组件页顶部新增同一工作面的极简 / 均衡 / 全特效材质对照，以及单次扫光、选中底板滑动、操作面展开和成果揭示；推荐布局输入框、组件页真实命令面板与菜单同步使用局部玻璃。
- **设置页面**：完整设置工作面，支持分类导航与主题预览；返回原布局时保留任务和草稿。

顶部「浅色 / 深色 / 跟随系统」与布局独立，所有预览使用一致的主题选择。A/B/C 不代表计划新增三个正式产品主题。

所有配置交互只影响当前预览，不修改真实设备或项目设置。首轮布局入口保存在 `index-layout-only.html`，独立玻璃实验时期的入口保存在 `index-glass-study.html`。单页与同目录 CSS / JS 一起保留。

材质样稿参考 Animate UI Highlight / Shine 与 React Bits Glass Surface / Border Glow 的视觉思路，未引入其运行库、付费源码或完整折射渲染。新增的 `material-*.css` / `material-*.js` 与 HTML 同目录保留；图标和字体仍已内嵌。鼠标高光只在局部表面接收指针事件时更新，演示结束后没有循环动画；这不等于已经完成 Electron GPU / 功耗验收。依据见 `docs/research/kodax-glass-motion-refinement-2026-10-16.md`。

已在实际侧栏浏览器中验证跨项目会话切换与草稿恢复、设置搜索与往返、主题同步、工作流人工确认、成果审阅、命令搜索和减少动态效果。记录见 `previews/verification-v2.json`；最新实拍为 `previews/projects-live.jpg`、`previews/settings-dark-live.jpg` 和 `previews/components-live.jpg`。

若浏览器限制 `file://` 中的 iframe，可从仓库根目录启动静态预览：

```powershell
python -m http.server 4178 --bind 127.0.0.1 --directory docs/design/space-ui-exploration
```

再打开 `http://127.0.0.1:4178/`。端口可自行更换。
