# v0.1.47-beta.1 release qualification

日期：2026-11-15。用户指定 Space `0.1.47-beta.1` 预发布；精确依赖 npm Registry `@kodax-ai/kodax@0.7.97-beta.10`（`sha512-33dnqhfDgrYy0OH++TiH3GiKS3m/KNSgItxYd4H6dpURV8G8rGCCZeeH96bBFWRnQQGgHUrf9msndAAtKMgQLQ==`），四个 workspace 与 lockfile 统一 Space 版本。稳定版保持 v0.1.46，不向正式版自动推送预发布。已发布的 alpha.4（beta.1 构建）与 alpha.5（beta.4 构建）记录保留为上一轮发布历史。

## 发布范围

- SDK beta.5 → beta.10 接入，见 [beta.9 适配](kodax-beta9-space-adaptation.md)、[beta.8 适配](kodax-beta8-space-adaptation.md)与[beta.7 适配](kodax-beta7-space-adaptation.md)。beta.10 把一次接受的多条排队输入合并进同一条 canonical 用户消息（`inputIds` 记名），Host 重启不再重复执行已合并输入；Space 显示合并后的单条消息。beta.9 发布 `copyKodaXDataRoot`、排队 steer 在安全点前可取回、共享 Host 退出保护与启动错误引用修复；beta.8 把 Windows Coder 启动改为带哈希校验的原生 Job 监督（Issues 245–247）；beta.7 落地每 `KODAX_HOME` 一个 Host（ADR-075）、Host 固定输入图片与 Agent home workflow。
- 数据位置（F148，[ADR-011](../ADR/ADR-011-settings-data-root.md)）：Settings → 常规 → 数据位置支持更换位置、验证与可选复制；设置保存在数据根之外，`KODAX_HOME` 统一为唯一数据根变量（`KODAX_PROFILE_DIR` 弃用别名）。
- 对话实时工作显示：live 工具组按工具族显示计数与耗时、最近动作与 thinking 实时滚动，等待审批显示手势，失败工具卡显示红色 failed 徽标；Run spinner 固定在 composer 上方并显示 token 用量；子 Agent 等待显示 "Agents working: N" 实例行；script 模式工具在工具组内按真实工具呈现。
- 转录窗口化（F144）成为默认：只挂载视口附近消息，长会话滚动、翻页与跳转保持流畅；历史导航、搜索定位与问题轨跳转语义保持。
- 侧栏：筛选菜单替换为单个"显示已归档会话"开关；项目保持加入顺序、拖拽顺序保存在 `projects.json`（dev 与打包版共享）；会话置顶优先、按最近活动排序。
- 修复（Issues 248–252 及回访）：Linux 升级在锁定 keyring 下不再永久阻塞启动；发送以换行结尾的草稿后 composer 完全清空（Issue 249）；与 `kodax` CLI 共享 Host 时退出只清理本客户端（Issue 250）；排队消息取回把文字放回 composer；多问题提问跳过当前问题保留其余答案；Run 结束后"返回最新消息"不再滞留。
- 当前 README、文档索引、PRD/HLD/DD、能力/凭据台账、用户手册、版本设计、内置技能记录与应用内 `space_manual`（runtime-host、composer、permissions、ui-map、sessions、agent-coordination）同步 beta.10 / beta.1 基线。SDK 自有 `kodax_manual` 不被覆盖。

## 验证与发布门

- 本地 Windows 完整源码检查：typecheck、lint（`--max-warnings 0`）、`npm run test:release`（161 项，154 通过、7 项 Windows symlink 权限条件跳过、0 失败）与 workspace 单测（electron/renderer/schema）全部通过；`npm run build:win` 完成 Windows 打包并跑通 boot/complete-exit 成品 smoke。
- space_manual 主题更新配套新增 beta.10 与对话实时显示的 manual 断言（`space-manual-topics.test.ts`），本地 17 项全部通过。
- 发布需同一 SHA 的四平台完整源码检查、成品构建和成品消费验收。Mac arm64/Intel 在候选归档前通过 `codesign --verify --deep --strict`；Windows 打包 smoke 继续校验 SDK 原生资源哈希。
- 最终 SHA、运行链接、平台结果与资产校验记录在 [本版发布验证](v0.1.47-beta.1-release-verification.md)。该记录未确认的项目不得以源码通过替代。

## 保留边界

- macOS ad-hoc 不等于 Developer ID 或公证，首次启动仍可能有 Gatekeeper 提示；通知/图标角标需要系统权限，macOS 仍手动下载 DMG 更新。Windows 安装器未签名。
- SDK Repo-intelligence Host 真实诊断/预热等接缝沿用 [beta.1 完整验收](kodax-beta1-full-acceptance.md)与 beta.2/beta.3 记录；不因升级宣称已消失。
- Issue 371 首次历史读取延迟仍未关闭，Host ready 不等于历史加载完成。不因升级宣称所有恢复性能或智能质量问题已解决。
- 外部账号、真实模型质量/计费、覆盖安装/断电、客户 Kylin/真实 Mac 权限设置仍需对应环境验收。
