# v0.1.46-beta.2 release readiness

Date: 2026-09-13. Previous release: v0.1.46-beta.1.

## Scope

- Pin the exact published KodaX `0.7.96-rc.4`, superseding rc.3. Every rc.3 contract is
  retained. rc.4 initializes new Session event journals at sequence zero instead of scanning
  unrelated Run logs — removing the synchronous startup stall that could push concurrent
  Session history reads past their 15-second timeout (Issue 214) — binds cached event-sequence
  floors to their journal epoch so missing or corrupt sequence files recover the durable log
  maximum without duplicating sequences or losing replay progress (SDK Issue 334), and
  populates Full RepoIntel routing and preturn caches during startup prewarm from one worker
  result.
- Fix Issue 211: real Coder sessions ask the Runtime to allocate and persist the Session and
  construct the Space host Session from the returned daemon-generated ID — no `sessionId`, no
  historical lookup before the first send. Partner, embedded Coder, mock providers and
  forced-mock runs keep local SDK ID allocation; resume, fork and existing Session admission
  keep persisted ownership and identity checks. A strict-history timeout before Run admission
  returns `accepted: false` with the new `session_history_unavailable` rejection reason; the
  composer restores the exact draft, unchanged retries reuse the same Session with a new
  operation ID and produce one visible user query, and Quick Ask recovers the same way.
- Fix Issue 212: the pending-send spinner keeps its elapsed time across rerenders and labels
  local preparation (credential binding, history admission) as preparation instead of model
  work, in the main composer and Quick Ask.
- Record Issues 211-214 in KNOWN_ISSUES with regression guides, the admission plan, and the
  `scripts/diagnostics/session-startup-history.mjs` startup diagnostic (Issue 213 observation).
- Add Playwright coverage for the send-retry flow and switch the packaged complete-exit probe
  to verify the Space-created Runtime identity via `sessions.load`.
- Synchronize workspace versions, changelog, READMEs, capability ledger, product/architecture/
  usage docs, user manual, feature list, `docs/features/v0.1.46.md`, and kodax_manual.

## Qualification

Typecheck passed; lint passes with zero warnings; the full unit suites passed with 0 failures,
including the release-gate scripts suite (rc.4 compatibility gate, daemon-control and
fresh-session probes against the installed published package), the desktop suite with the new
session-create-runtime and spinner tests, and the ipc-schema workspace suite. The Issue 211-214
regression guides describe the human acceptance passes.

## Remaining boundaries

Issue 213 stays an SDK observation: rc.4 removes the duplicated routing query after prewarm,
but a first-run Full RepoIntel rebuild can still take seconds before model work begins; the
diagnostic script captures evidence. Pure configuration-type extension commands remain
CLI-owner-only. FEATURE_275 long-term guarantees are unchanged from beta.1.
