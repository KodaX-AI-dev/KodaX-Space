# HTML 幻灯片

沿用已有内容、品牌和用户指定的风格、页数及用途，交付可直接打开的 HTML 演示。简单修改优先保持现有文件结构。幻灯片内容与 HTML 是交付物，内部模板名、生成步骤和诊断标签不显示在页面里。

## 选择本次工作

- 新建 HTML 演示：从已知内容组织大纲。只询问缺失且影响结果的信息；未指定密度时依据投屏讲述或异步阅读的用途决定，并说明必要假设。
- 修改现有演示：先读取并保持其视觉系统，只改本次范围，检查受影响页面。
- PPT/PPTX 转网页：提取原文字、图像、页序和备注，按用户要求决定保持原样或重新设计。当前环境支持 Python 时可用 [提取脚本](scripts/extract-pptx.py)；不能读取的内容明确列出，不伪称完整保留。
- 用户要求原生可编辑 PPTX：使用当前已注册且支持该格式的工具；HTML 或静态 PDF 不等于可编辑 PPTX。

## 视觉方向

需求明确时直接制作一个符合要求的版本。用户希望比较风格时才生成适量代表页，不固定询问四个问题或强制三份方案。已有参考和已确认风格直接复用，后续局部修改不重新进入风格选择。

按需读 [STYLE_PRESETS](STYLE_PRESETS.md) 和 [模板索引](bold-template-pack/selection-index.json)。只读选中候选的 preview，正式采用时再读其 design 文件；自定义方向可以直接从客户内容发展，不必套入库中。

## 实现约定

生成前读 [HTML 架构](html-template.md) 与 [viewport CSS](viewport-base.css)，需要动画时才读 [动画参考](animation-patterns.md)。

- HTML 演示保持固定 1920×1080 的 16:9 舞台，整体缩放；手机上也不重排幻灯片内容。
- 使用 viewport-base.css 的 active/visible、visibility、opacity 和 pointer-events 切页，避免 display 规则相互覆盖而显示所有页面。
- 内容溢出时重排或分成更多页，不靠无限缩小字体。投屏和异步阅读的密度按用途取舍。
- 保留 reduced-motion、键盘导航及需要的触屏操作。编辑功能仅在实际实现并验证后说明可用。
- 尽量以单文件包含 CSS/JS；按客户离线/分享要求内嵌资源或携带资源目录。优先品牌和可用字体，提供字体回退，不强制依赖外部字体网站。

脚本相对本 Skill 根目录定位，输入输出路径显式给出。通过宿主实际可用的方式预览文件，按 Windows/POSIX 环境选择工具，不默认 open、brew、Bash 或全局 Python 已存在。缺少导出依赖时使用现有替代能力或说明具体缺口，不自行改变系统环境。

## 验证与交付

渲染并检查文字、图片、溢出、遮挡、导航和用户需要的交互；检查目标投屏尺寸及相关的小屏状态。源码或 scrollHeight 单项检查不能代替可见结果。交付最终 HTML 及其所需资源，报告实际检查范围和必要使用方法。

PDF 导出按用户需要使用 [导出脚本](scripts/export-pdf.sh) 或宿主现有能力；先确认依赖可用，并说明静态 PDF 不保留动画和交互。临时预览仅清理本任务生成且已经不需要的文件。
