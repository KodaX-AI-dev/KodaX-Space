## 实现（2026-11-14）

用户确认「可以，按这个来吧」后落到产品代码：

- `apps/desktop/renderer/src/shell/toolClusterPulse.ts`：纯投影（节拍条、动作行、思考末行、耗时起点、token 估算）。
- `apps/desktop/renderer/src/shell/ToolClusterLive.tsx`：节拍条、动作流组件，FLIP 上推。
- `ConversationStreamV2.tsx` 的 `ToolCluster`：运行中（`followTail`）显示转圈 + 流光 + 动作流 + 耗时/token，结束时 ok 光环，节拍条留在历史标签上。`groupTools` 把工具之间的尾部思考并进运行中的工具组，避免标签在两次调用之间闪断。
- 耗时来自 SDK 产品条目的 `tool.startedAt` / `endedAt`；旧事件拼接的历史没有耗时，节拍条用中等高度。
- 动效档位：流光只在 full 档；极简档全部静止；`prefers-reduced-motion` 全部关闭。
