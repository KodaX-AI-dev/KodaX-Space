# Space 内置技能内容改进验证

本指南记录 2026-10-27 的 F135 内容改进阶段，当时 Space 依赖 SDK 0.7.97-alpha.9。2026-10-28 已继续接入发布包 alpha.10；正式依赖升级及 Runtime 适配的当前结果见 [alpha.10 接入记录](../releases/kodax-0.7.97-alpha.10-integration.md)。这些工作区改动不代表新的 Space 安装器已经发布。

## 改动范围

- 保留 18 个技能和自然语言发现，按交付类型及用户目标精简触发描述。
- Huashu 使用 3.0 上游来源，copywriting 使用 2.3.1，customer-research 使用 2.0.4，call-prep 使用审阅过的新来源。其他 7 个借鉴技能保持原始固定版本，在 Space patch 中调整内容。
- 设计、客户沟通和资料综合按任务交付；已知信息和方向不重复确认。保留真实内容、实际渲染及授权边界。
- 第一方方法仅调整飞书 Base 设计与创建的衔接、短研究的交付方式。专家上架状态、连接器权限、SDK 依赖和 Runtime 协议不在本轮修改范围。

## 自动验证

运行 npm run skills:check，确认来源、patch、锁文件、完整分发文件和相对链接一致。运行 node --test scripts/test/sync-builtin-skills.test.mjs，确认同步器仍拒绝漂移、越界和损坏链接。

运行 node --test --test-concurrency=1 --import tsx apps/desktop/electron/test/space-builtins.test.ts，确认实际 Host 注册、独立 Artifact 失败降级、内置技能清单和安全过滤仍符合原契约。检查 Space 与 SDK 的 package.json/package-lock.json 没有被升级或重写。

修改 sourcePath 技能时先改 resources/first-party-skills；修改借鉴技能时改来源及 patch，再通过 npm run skills:update 重建完整快照。发布门使用精确 Git ref，不使用开发机已安装副本代替来源。

本地已执行：18 个快照的 skills:check 通过；同步器 11 项通过，2 项因 Windows 符号链接权限跳过；Host 测试 10 项通过。独立前向任务验证了短客户回复、仅修改按钮、制度与聊天建议冲突的综合，以及现有 HTML 仅改标题。最后一项已实际查看 1920×1080 和 390×844 渲染，并确认源码仅标题变化、导航可用、无页面错误。这是四个具体场景的烟测，不是模型质量的统计评测。

Space 两轴复审最终均无剩余发现。复审中发现的 Huashu 可达参考仍要求三方向、固定导演稿和重复确认的问题，已通过源 patch 统一修正，包含分镜定位、可选模板、灰盒配方、完成检查及幻灯片格式路由，并再次用官方同步器重建快照。

## 客户场景

| 场景 | 检查行为 |
|---|---|
| 已有 HTML 演示只改标题或一张图片 | 保持现有结构与方向，直接完成相关修改，不重新给风格问卷或三份新稿 |
| 用户已给品牌、内容和风格并要求直接制作 | 沿用材料推进；仅缺少影响交付的关键选择时询问，不在内部阶段反复停轮 |
| 用户明确要比较不同视觉方向 | 提供与任务规模相称的真实代表内容，解释差异；选择后继续完成 |
| 明确要求可编辑 PPTX | 使用实际支持该格式的能力；不以 HTML、PDF 或整页截图冒充原生可编辑文件 |
| 80 字以内的客户微信回复，无已确认修复时间 | 只给可发送正文，保留未知和实际绕行方法，不补造负责人、时间或主动跟进承诺 |
| 仅替换营销按钮，试用价格未知 | 只修改目标文案，保持其他内容；不补“免费”、提醒或自动化等未知能力 |
| 旧的生效制度与新的未批准聊天建议冲突 | 区分效力与时效，引用适用制度并保留建议状态，不机械选择最新材料 |
| 客户会谈准备缺少 CRM/日历连接 | 使用已提供材料，说明覆盖范围；未查询、无结果和不存在分别表达 |
| 三句话快速研究结论 | 当前会话直接交付与引用，不强制新建报告或重复长模板 |
| 用户授权设计并创建飞书 Base | 根据需求形成可用 schema；只询问会实质影响创建的缺口，按真实工具回执报告结果 |

## 完成边界

静态内容、来源和文件完整性验证不能代替模型输出质量及真实 GUI 验收。无渲染能力时明确标记未验证；可选 Python、浏览器、导出和云处理仅在实际需要且可用时采用。本轮不声称所有上游脚本、中文字体、PPTX 转换或跨平台渲染均已验证。

SDK 本轮复审基线为 6d101b59，目标为 3a32e04b：两轴无发现，相关测试 121 项、独立 npm-pack 技能脚本链 1 项、Windows 真实退出 2 项以及源码类型检查通过。原始 Skill 缺失反例已返回 local_execution/skill_load/skill_not_found，Provider 请求数为 0。此结果是本地 SDK 验证，不代表 Space 已消费新发布包。
