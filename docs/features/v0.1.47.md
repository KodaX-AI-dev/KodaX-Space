# KodaX Space v0.1.47

> **2026-10-11 alpha.1（0.1.47 线开启）**：首个 alpha，精确接入已发布的 KodaX `0.7.97-alpha.3` 统一公共契约。这是 v0.1.46 已有能力的依赖与契约迁移，不新增客户端产品、服务器或应用配置：稳定 Product 输入与 Main 授权捕获（稳定 inputId，重试/队列/steer 复用原授权快照，秘密不经过 Renderer/IPC）、Host 持有的 Workflow 政策（maxAgents/tokenBudget/并发上限，目录由 Host 管理）、canonical 历史/当前视图（sourceRevision 守卫边界、opaque item ID 区分同 model toolId 的多次执行）、SDK statistics（累计用量/物理请求/上下文组成/逐工具 Sandbox 原始事实，partial/unknown 保留，不再用 permissionMode 推断实际执行）、以及可恢复客户端退出（同一 requestId 的接受/工作清理/精确退出回执，其他客户端保护，接受退出后 Main 身份轮换；unknown 不当作成功）。journal/replay 与旧完整退出 API 移除。既有 Coder/Partner 隔离、可信 Main 凭据与 Host Tools、共享设置与 Shell 合同、历史与实时输出身份规则（ADR-009）全部保留。完整接缝清单、范围校正与验收见 [SDK_0.7.97_MIGRATION](SDK_0.7.97_MIGRATION.md)。

> 版本线：`0.1.47`（预留块见 [FEATURE_LIST 版本计划](../FEATURE_LIST.md)）。0.1.46 稳定线（Space v0.1.46 / KodaX 0.7.96）保持最新稳定发布，本线在其之上迁移契约。

## 接入落点

- 启动仍用 ensure、重连用 passive connect，按真实能力版本拒绝不兼容 Host；启动要求 `sandboxRuntime:11`、`runtimeAutoModeGuardrail:6`、`sharedSessionSettings:2`、`effectiveConfig:1`，daemon 准入另需 `providerCredentialBroker:2`，打包依赖 smoke 要求 `conversationHistory:2` 与 `runtimeExitSettlement:2`。
- 普通输入走 `acceptInput`，显式工具走带 inputId 与 authorization 的工具入口；技能、命令 hooks 与 review 的准备由 Host 完成，Partner 保留自己的 inline 执行边界。
- 重连从 SDK 当前 view/snapshot 重建（不再有 journal/replay）；长 view 正文校验长度、revision、offset 与读取期限，过期 canonical 边界拒绝。
- Space 手册经现有只读 Host Tool `space_manual` 组合安装 SDK 手册与 Space 操作说明；发布 SDK 拒绝覆盖内建 `kodax_manual`。
- Stop 后新输入 admission 期间的观察订阅不再过早退役（stop-then-send 保持 Session observer 附着，live 输出照常到达）。
