# v0.1.47-beta.4 release qualification

日期：2026-11-22。用户指定 Space `0.1.47-beta.4` 预发布；SDK 保持 npm Registry `@kodax-ai/kodax@0.7.97-beta.13` 精确依赖不变，四个 workspace 与 lockfile 统一 Space 版本。稳定版保持 v0.1.46，不向正式版自动推送预发布。已发布的 beta.3（beta.13 构建）及更早 beta/alpha 记录保留为上一轮发布历史。

## 发布范围

- F149 侧栏生命周期（本版主体，无 SDK 变更）：左侧栏新增全局"置顶"区，位于"项目"标题之上、仅在存在置顶内容时显示——置顶任务在前（最近置顶的最上，置顶期间离开所属项目列表），置顶项目带各自任务列表排在其后，可在置顶区内拖排且不影响主列表；取消置顶后任务按时间回到项目、项目回到主列表原保存位置，"置顶项目"不再把项目移到主列表顶部。
- 项目列表收敛为一个保存在 `projects.json` 的手动顺序：新加入项目仅在添加时置顶一次，打开或使用不再移动；升级后首次启动按当前显示顺序落盘。项目内运行中的任务按创建顺序固定在前（流式输出时行不再互换），其余按最近活动；Fork 任务在侧栏与 "+N more" picker 中平铺。
- 先归档、再删除：任务/项目右键菜单与任务面包屑菜单提供归档，删除/移除仅对已归档条目提供；悬停任务行显示置顶与归档按钮；归档会取消置顶，取消归档不恢复置顶；任务置顶与归档状态保存在 `session-flags.json`，重启保持，删除任务清除。见 [F149 设计](../features/v0.1.47.md#feature_149-sidebar-pinned-area-stable-ordering-and-archive-first-lifecycle)与[人工测试指引](../test-guides/FEATURE_149_v0.1.47_TEST_GUIDE.md)。
- Composer `@` 补全列出项目文件夹（候选带尾随 `/`，与文件共用同一套 `.gitignore` 排除规则，经 `project.fileSearch` 新增 `includeDirectories` 输入选择启用，链接定位与 Files 列表仍只列文件），选中的文件夹成为 `@dir/` 文件夹引用；技能/命令行内标签不再重复 `/` 与 `/skill:` 前缀（图标区分类型）；历史里的 `/name` 技能与命令按命令目录区分、文件/文件夹引用与 composer 同名显示，发送原文保留在 DOM 中（前缀隐藏），查找、复制与 e2e 文本匹配看到逐字文本。
- 当前 README、文档索引、Feature List、v0.1.47 设计、用户手册与应用内 `space_manual` 话题同步 beta.4 基线（F149 置顶区与归档生命周期、composer 文件夹补全与历史一致显示）。SDK 自有 `kodax_manual` 不被覆盖；SDK 版本与 beta.3 相同（0.7.97-beta.13，`actorSettlementConvergence` v3 等能力门沿用 beta.3 记录）。

## 验证与发布门

- 本地 Windows 完整源码检查：typecheck、lint（`--max-warnings 0`）、workspace 单测（desktop electron/renderer、ipc-schema）与 `npm run test:release`（含 `skills:check`、原生资源预热与 `scripts/test/*.test.mjs`）全部通过（2026-11-22）。
- 发布需同一 SHA 的四平台完整源码检查（ci.yml E2E 双分片 + build.yml 四平台 smoke、静态检查与门禁）、成品构建和成品消费验收。Mac arm64/Intel 在候选归档前通过 `codesign --verify --deep --strict`；Windows 打包 smoke 继续校验 SDK 原生资源哈希与内置 Skill 解包完整性。
- 最终 SHA、运行链接、平台结果与资产校验记录在发布后补记的验证文档（`v0.1.47-beta.4-release-verification.md`）。该记录未确认的项目不得以源码通过替代。

## 保留边界

- macOS ad-hoc 不等于 Developer ID 或公证，首次启动仍可能有 Gatekeeper 提示；通知/图标角标需要系统权限，macOS 仍手动下载 DMG 更新。Windows 安装器未签名。
- `session-flags.json` 为 Space 自有状态（任务置顶/归档），不写入 SDK 会话文件；项目顺序仍在 `projects.json`。
- Issue 371 首次历史读取延迟仍未关闭，Issue 254（Run 期间历史翻页重复/乱序）推迟到下一大版本，本版保持 SDK 0.7.97-beta.13 与现有缓解；SDK Repo-intelligence Host 真实诊断/预热等接缝沿用 beta.1–beta.3 验收记录，不因本版（无 SDK 变更）重开或宣称消失。
- 外部账号、真实模型质量/计费、覆盖安装/断电、客户 Kylin/真实 Mac 权限设置仍需对应环境验收。
