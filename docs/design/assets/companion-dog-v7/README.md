# 思考、工作、等待确认与完成 · 完整工作区预览

2026-10-17。延续用户认可的v6待机与小狗造型，新增四种任务动作。仅修改设计预览；正式产品宠物、设置、任务功能和旧资源均未替换或取消。

## 当前动作

| 状态     | 动作与保持方式                             | 区别                                       |
| -------- | ------------------------------------------ | ------------------------------------------ |
| 思考     | 侧头向上观察，小幅调整头部角度、眨眼和停顿 | 目光向上、头部侧倾，脚掌落地               |
| 工作     | 低头看前爪，前爪交替轻压并留出检查间隔     | 目光向下、头部低伏与有节奏的压爪           |
| 等待确认 | 一次抬爪后保持，偶尔眨眼；确认后放下       | 不循环招手，不自动批准；抬爪后保持同一造型 |
| 完成     | 一次开心张嘴、点头回应与短摇尾，随后收住   | 不永久庆祝；状态仍为完成，动作可重播       |

入口为[完整工作区](../../space-ui-exploration/companion-workspace.html?theme=dark)。默认待机，可单独切换动作或点击「播放流程」；流程在等待确认处停下，点击中间的「示例确认，看看完成动作」后才继续。其他预先规划的动作仍明确标为待补帧，不代表产品功能取消。

## 素材与一致性

固定沿用[原造型](../companion-dog-v3/character-anchor.png)，待机直接复用v6原图集及帧序列。内置imagegen只编辑目光、嘴部或前爪局部；[完整提示词与使用清单](prompts.json)记录最终采用及弃用的候选。所有引用素材已保存于本目录，生成原文件仍保留于Codex generated_images。

思考和工作取局部目光原画；完成取两档张嘴原画。头部与压爪的连续变化在离线制片时对同一完整位图局部采样生成，原图中的躯干与其他部位保留。等待使用9张同画幅的抬爪原画，冻结头部、项圈、尾巴和取景，只更换前肢及其显露的胸腹区域。没有把每帧都重新生成的整只狗直接轮播。

等待方案的4×4原画表因身体变宽弃用；两个端点的图像补间因出现重影弃用，相关实验脚本已移除。最终采用原图单独编辑的低、中、高抬爪原画，未使用有重影的补间或身体比例错误的帧表。静止段复用位图；原画数量、合成位图数量和播放步数分别记录，不能相互冒充。

| 状态     | 合成完整位图 | 首次播放步数 | 播放方式                                 |
| -------- | ------------ | ------------ | ---------------------------------------- |
| 待机     | 83（原v6）   | 192          | 24fps，8秒循环                           |
| 思考     | 42           | 88           | 24fps，进入后仅循环观察段                |
| 工作     | 34           | 64           | 24fps，进入后仅循环工作段                |
| 等待确认 | 12           | 88           | 24fps，进入后仅循环静止/眨眼段，不重抬爪 |
| 完成     | 54           | 84           | 24fps，单次3.5秒，最后停在中性姿态       |

[帧表](frames.json)中的每个状态都从相同中性完整帧开始。切换时从当前可见帧沿预制收束路径回到中性，再进入目标动作；无双姿态淡化、骨骼拼接或运行时身体形变。连续快速切换以最后一次选择为准。减少动画显示该状态的有意义静态姿态，例如等待时保留抬爪。

## 实际播放复审

检查对象是浏览器中实际播放的完整工作区，包含侧栏停靠小狗和120px放大观察。截图采样约12.5fps，网页播放为24fps；截图数不是源原画数。

- 思考、工作、完成各原速录取9秒。思考/工作覆盖多轮；完成后持续停留，确认没有再次庆祝。[原速观察图](../../../../artifacts/companion-states-v7/four-actions-actual.png)。
- 完整流程原速录取22.2秒，实际经过待机→思考→工作→等待确认，停在等待；[播放相位记录](../../../../artifacts/companion-states-v7/actual-flow/times.json)。确认后另录5.4秒，经过放爪、完成回应并显示「已收住」。
- 浅色主题0.5倍速：等待、思考、工作各8秒，完成10秒。[抬爪进入观察图](../../../../artifacts/companion-states-v7/waiting-entry-actual.png)、[半速动作观察图](../../../../artifacts/companion-states-v7/four-actions-slow-light.png)。检查了脚掌、肩部、颈部连接和状态收束，未采用此前有重影或比例错误的候选。
- 40/64/120px尺寸均操作检查；原实际停靠尺寸始终同时播放。减少动画时切换到等待会直接保持抬爪，间隔读取的绘制计数均为671。暂停、逐帧、速度与重播入口保留。
- 浏览器warning/error为空。复审不是仅凭帧数、刷新率或单张截图判断。

## 性能与验证

运行时只裁切完整PNG位图，按需解码当前动作；保留当前、上一动作的Image引用，并在切换时预载目标图集，释放不再使用的引用。等待静止段、完成收住、暂停、后台与减少动画不重复绘制相同位图。新原画与制片脚本不进入运行时；未新增依赖。

四种新图集PNG约2.5MB。RGBA单图解码大小约：思考12MiB、工作10MiB、等待4MiB、完成14MiB，按需加载。原待机图集约22MiB。这里是图集的像素存储估算，不将其当作浏览器总内存测量。
