# v0.1.46-rc.4 release readiness

Date: 2026-09-23. Previous release: v0.1.46-rc.3.

## Scope

- Pin the exact published KodaX `0.7.96-rc.11` in root/Desktop manifests and the lockfile
  (`sha512-hMNSprQA1JF0arG0iz8I3PP27WLIw848HqkR1gG2nTNC0ttsoODi4zIVDJRSbnkIyOl/+wBsdnTgUNSEEK8F1g==`),
  superseding rc.10. Public capability versions and the existing startup/daemon gates
  (`sandboxRuntime:11`, `runtimeAutoModeGuardrail:6`, `sharedSessionSettings:2`,
  `providerCredentialBroker:2`, `effectiveConfig:1`, daemon `sessionCancellation:1`
  with durable frontier, `toolInvocation:1`) are unchanged.
- Issue 217 (background Git queries repeatedly triggered the macOS developer-tools
  installer, tracked in [KNOWN_ISSUES.md](../KNOWN_ISSUES.md)): on macOS without
  command-line developer tools, the system Git executable is an Apple launcher that
  shows the install dialog before ordinary failure handling; Space project queries,
  workspace `git init`, and SDK background Git calls could reach it, and cancelling
  did not stop later prompts.
  - Space guards its two Git spawn sites with the SDK's shared check via the new
    `assertNoGitInstallPrompt` adapter: the project Git runner returns its existing
    failed-result shape (`{ ok: false, stdout: '' }`) after keeping the 5-second
    timeout and 1 MB output cap, and settings keeps its nonfatal startup warning path.
  - The check applies only on Darwin when the selected executable resolves to
    `/usr/bin/git`; it runs `/usr/bin/xcode-select -p` with matching cwd/environment
    and blocks only on exit code 2. Uncertain probe failures preserve the original
    Git attempt. Determinate results cache for 5 seconds and recover on later refresh
    without restart. Independent Git, effective PATH ordering and DEVELOPER_DIR remain
    valid. Windows and Linux never load the adapter's SDK path; arbitrary user/model
    Bash or PTY commands stay outside the guard.
  - The SDK adds the shared check and lets repo-intelligence recover to Git-backed
    analysis from unborn repositories; synchronous memory identity and worktree
    failure semantics are unchanged.
- Synchronize workspace versions, changelog, READMEs, capability ledger, product/
  architecture/usage docs, user manual, feature list, `docs/features/v0.1.46.md`, and
  kodax_manual (rc.4/rc.11 stamp with anchored contract test), plus the
  [Issue 217 regression guide](../test-guides/ISSUE_217_v0.1.46-rc.3_REGRESSION_GUIDE.md).

## Qualification

- Recorded during the 2026-09-23 integration: the release dependency gate downloaded
  the official rc.11 tarball directly after Registry propagation, verified its SHA-512
  against the lockfile, and compared every installed package file and required native
  artifact; no development link remains. Typecheck, the main-process build, installed
  builtin-skill verification, and the release test suite (86 pass / 7 platform
  skips) passed; the focused four-suite regression run passed 40 tests with one
  Windows symlink skip, covering all five Issue 217 regressions. A simulated-Darwin
  smoke verified blocked system Git and available independent/installed Git through
  both the published SDK and the Space adapter. Release-mode Windows packaging,
  packaged dependency/native/worker checks, boot smoke, and two clean exits with
  Session history recovery passed.
- The manual-topics contract pins the rc.4/rc.11 phrasing and the macOS preflight note.

## Remaining boundaries

Native macOS acceptance (no-dialog matrix on a machine without developer tools and an
available-Git machine) remains pending and is documented as manual steps in the
regression guide; this Windows host cannot execute it. The guard intentionally does
not cover arbitrary user/model Bash or PTY commands. Pure configuration-type extension
commands remain CLI-owner-only; Partner Coder sharing, real external-account
acceptance, and automatic library replacement remain open from earlier readiness
records. FEATURE_275 long-term guarantees are unchanged.
