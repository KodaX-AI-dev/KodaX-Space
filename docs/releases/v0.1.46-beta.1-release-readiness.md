# v0.1.46-beta.1 release readiness

Date: 2026-09-13. Previous release: v0.1.46-alpha.11.

## Scope

- Pin the exact published KodaX `0.7.96-rc.3` in root/Desktop manifests and the lockfile,
  superseding the rc.1 baseline that alpha.11 shipped. The rc.2 intermediate verified that
  stale first Session Stop requests are rejected atomically without cancelling successor Runs,
  moved accepted-request replay to the owner, removed obsolete client acceptance bookkeeping,
  and settled exact-Run daemon retries from terminal receipts.
- Require daemon `sessionCancellation:1` with a durable frontier plus `toolInvocation:1` at
  startup. Published-package daemon tests verify explicit write/bash execution, current and
  queued Run cancellation, accepted-request replay, stale first-request rejection, and
  successor survival. Space recognizes structured stale errors under daemon `error.data` and
  removes the rc.2 Run-only Session Stop fallback. SDK connection fencing owns safe stale-owner
  replacement; no Space recovery manager is added.
- Fix duplicate/out-of-order explicit command messages before a renderer reload: explicit tool
  Runs legally omit a model turn ID, so Space matches their single completed tool invocation to
  the unique canonical input by the existing tool-call ID, keeps ambiguous inputs and unrelated
  late events visible, and reuses the existing history merge without new SDK interfaces or
  retirement authority.
- Verify through packaged live acceptance (rc.2, DeepSeek): Stop/retry, successor survival,
  two native PNG-reading child agents, and renderer reload. The acceptance harness now lives at
  `scripts/test/sdk-live-acceptance.mjs`.
- Synchronize workspace versions, changelog, READMEs, capability ledger, product/architecture/
  usage docs, user manual, feature list, `docs/features/v0.1.46.md`, and kodax_manual.

## Qualification

Typecheck passed; lint passes with zero warnings; the full unit suites passed with 0 failures,
including the release-gate scripts suite with the rc.3 published-package daemon control probes
(`kodax-daemon-control.test.mjs`), the desktop suite with the rc.3 compatibility gate, and the
ipc-schema workspace suite. The F274 test guide records the packaged live acceptance evidence.

## Remaining boundaries

Blue-PNG color recognition remains inconsistent in the packaged live acceptance. Pure
configuration-type extension commands still have no public remote execution endpoint and stay
with the CLI owner. FEATURE_275 long-term guarantees are unchanged from alpha.11: bounded
memory together with replay that never resurrects unknown inputs still requires SDK/main-side
persistent exact identity queries or a full delivery-batch coverage proof.
