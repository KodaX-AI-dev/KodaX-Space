# v0.1.47-alpha.1 release readiness

Date: 2026-10-11. Previous release: v0.1.46 (latest stable).

## Scope

- First alpha of the 0.1.47 line: pin the exact published KodaX `0.7.97-alpha.3` in
  root/Desktop manifests and the lockfile, superseding stable `0.7.96`, and migrate Space
  to the SDK's unified public contracts — stable Product input with captured Main
  authorization (stable inputId; retry/queue/steer reuse the original snapshot; secrets
  never cross Renderer/IPC), Host-owned Workflow policy (maxAgents/tokenBudget/`config.workflow.maxConcurrency`;
  run directories Host-managed), canonical history/current views (sourceRevision-guarded
  boundaries, opaque item IDs), SDK statistics (cumulative usage, physical requests,
  context composition, per-tool sandbox facts; partial/unknown preserved), and recoverable
  client exit (accept/work-cleanup/exact-exit receipts, other-client protection, Main
  identity rotation after accepted exit; unknown is never success). The journal/replay
  path and the old complete-exit API are retired.
- Keep every existing product boundary: Coder/Partner isolation, trusted Main credentials
  and Host Tools, shared settings and Shell contracts, history and live-output identity
  rules (ADR-009). The Space manual composes through the read-only `space_manual` Host
  tool; Stop-then-send keeps the Session observer attached during new-Run admission.
- Synchronize workspace versions, changelog, READMEs, capability ledger, product/
  architecture/usage docs, user manual, feature list, `docs/features/v0.1.47.md`, and
  kodax_manual. Full delta audit and seam-by-seam acceptance:
  [SDK_0.7.97_MIGRATION](../features/SDK_0.7.97_MIGRATION.md).

## Qualification

Typecheck, lint, and the full unit suites pass locally with 0 failures (`npm test`:
4,332 items — release 92, Desktop 3,855, IPC 365, plus 20 platform/conditional skips).
The 30-seam migration coverage set passes at 97.77% line / 87.04% branch coverage.
Source E2E passes 99/99 (93 existing desktop + 6 real published-SDK) and the same real
SDK suite passes 6/6 from the packaged directory; packaged dependency/boot/SDK gates
pass. Manual-topics contract pins the v0.1.47-alpha.1 / 0.7.97-alpha.3 phrasing.

## Remaining boundaries

Existing UI suites include mock/injected scenarios; real-model, real external-account,
and other-OS acceptance are not covered by this alpha. unknown exits, lost exit ACKs,
and Main rebuilds are proven by public SDK integration regressions, not by packaged E2E.
Pure configuration-type extension commands remain CLI-owner-only; Partner Coder sharing
of experts/connectors remains a follow-up. F022 updater policy (darwin disabled, silent
NSIS on Windows) is unchanged.
