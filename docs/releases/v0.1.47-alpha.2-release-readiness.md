# v0.1.47-alpha.2 release readiness

日期：2026-10-15。目标：Space `0.1.47-alpha.2` 预发布；用户已确认版本。本记录不代表已创建 tag、推送或发布 GitHub Release。

## 发布范围

- root、Desktop、IPC schema 和 UI kit 统一版本，SDK 精确锁定正式 Registry `@kodax-ai/kodax@0.7.97-alpha.6`。不携带 sibling SDK 源码，不补丁依赖字节。
- 共享 Coder 直接消费 SDK 当前 view，并将历史分页/搜索独立显示。保留用户图片、长正文、工具、Artifact、重复输入身份和 revision-bound Fork/Rewind；初始快照与实时帧有序替换。
- 普通新会话要求 SDK/Host `sessionDrafts:1`；旧空记录经完整历史确认后隐藏，原文件与可恢复状态保留。列表保留真实 `lastMessageAt`，不被元数据写入覆盖。
- SDK 启动阶段与等待原因投影到本地 UI；移除实时 Verifier 与 `/verifier-log`，保留 Stall logging、历史记录与 `visual-review`。
- SDK 内置 `relationship_scan.depth` 使用整数范围 1–3，修复 Gemini 路由的数字枚举兼容问题，不改 Provider 配置或流完整性校验。
- 修正 Space 产品手册入口：共享 Coder 使用 `space_manual`，`kodax_manual` 保留 SDK/CLI；补草稿、排序、独立历史与 Product lifecycle 退出说明。同步 README、文档入口、PRD/HLD/DD、用户/开发手册、台账与版本记录。
- 修正 live visual-review 验收脚本遗漏工具调用身份的问题，使 transcript/Host 图片证据可按真实调用关联。
