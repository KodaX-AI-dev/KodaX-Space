# v0.1.46 release readiness

Date: 2026-10-06. Previous release: v0.1.46-rc.6. **First stable release of the
0.1.46 line.**

## Scope

- Pin the published stable KodaX `0.7.96` in root/Desktop manifests and the lockfile
  (`sha512-7H/o0LhmlbeQsUnxGutSqMIb2Ms7UUS+kqNiPYChYT9G8Oni8RxB8ZxsDwiIlQ3ORPg4NwrDXQmKACab/uBVSA==`),
  superseding rc.14. The stable package is a fresh build of the rc.14 source:
  release bookkeeping only in the source diff (`cad8b658..c2c8fdc4`), but 19
  same-path files change, 21 generated JS chunks are replaced, and the Windows
  shell/text binaries and manifest hashes change — each qualified against the new
  manifest by the release dependency gate. Runtime behavior and public contracts
  retain the rc.14 implementation; installed exports, dependency ranges, engine
  requirements and `kodaxRuntimeContracts` equal rc.14. No capability gate moves
  (`sandboxRuntime:11`, `runtimeAutoModeGuardrail:6`, `sharedSessionSettings:2`,
  `providerCredentialBroker:2`, `effectiveConfig:1`, daemon `sessionCancellation:1`
  with durable frontier, `toolInvocation:1`).
- Ship every rc.6 contract and fix unchanged as the stable release: the Issue 216
  follow-up (credential self-heal, uninstall-safe AppData, terminal history errors),
  the Runtime UI convergence (unconfirmed runs, Stop settle, composer controls,
  Agent iteration limits), and the interrupted-history / queued-input recovery over
  rc.12–rc.14.
- Version the workspace `0.1.46` (no prerelease suffix): the GitHub release is
  stable, not a prerelease. Synchronize changelog, READMEs, capability ledger,
  product/architecture/usage docs, user manual, feature list, `docs/features/v0.1.46.md`,
  and kodax_manual (`v0.1.46` / stable `0.7.96` stamp; the anchored contract test
  derives the expected stamp from the manifest's declared dependency).
- This release also flips the "latest stable" claims: Space v0.1.46 / KodaX 0.7.96
  becomes the current stable pair; v0.1.45 / KodaX 0.7.95 turns historical.

## Qualification

- Recorded in the [stable integration verification](kodax-0.7.96-integration.md):
  the current-manual contract test first detected the intermediate mismatch between
  the stable manual and the rc.14 dependency, then passed 7/7 after installing the
  stable package. `npm test` passed 4,309 / 20 skip / 0 fail (release 92/7, desktop
  3,854/13, ipc-schema 363/0), including published-package managed/coding recovery,
  completed-output durability, Stop/queue and history-reconciliation regressions.
  Typecheck, lint, and build:smoke passed.
- The exact Registry dependency gate passed; packaged universal native files match
  their new manifest hashes, SQLite executes from ASAR, Runtime and
  constructed-handler Workers execute from the new package. Packaged boot passed
  (renderer 6,136 ms, Runtime 29,212 ms including the deliberate 20-second hold;
  122 historical child records retained); the packaged SDK reports `0.7.96`; the
  rebuilt directory app's main and 555 renderer files match the local build.

## Remaining boundaries

macOS auto-update stays disabled until builds are code-signed; the Issue 217 native
macOS acceptance remains pending; the Issue 216 customer-machine recovery has not
been executed against production data. Shell-cleanup recovery requires the matching
SDK (0.7.96) and Space deployment. Pure configuration-type extension commands remain
CLI-owner-only; Partner Coder sharing, real external-account acceptance, and
automatic library replacement remain open. FEATURE_275 long-term guarantees are
unchanged.
