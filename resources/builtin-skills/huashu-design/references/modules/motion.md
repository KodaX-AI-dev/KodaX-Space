# 动画与视频

先按 SKILL.md 确定本次格式、用途和范围。HTML 交互演示、GIF、无声视频和带音轨的成片分别交付；不默认增加额外格式、配乐或方向审批。

## 按需求读配方

- 短动画与概念演示：按需读 [分镜](../storyboard-basics.md)、[常见问题](../animation-pitfalls.md) 和 [镜头语言](../camera-language.md)。
- 产品 UI 演示：读 [UI 展示](../ui-demo-animation.md)，使用真实素材或注明重建内容，保持关键状态可检查。
- 品牌宣传片：按目标复杂度读 [导演稿参考](../launch-film-director-notes.md)，文档体量与任务相称，不强制定长导演稿。
- 有解说的内容：读 [解说配方](../voiceover-pipeline.md)，只在用户需要时制作音轨。
- 用户要求比较方向：按 [方向探索](../directions.md) 给适量代表关键帧，明确方向时直接实现。

## 实现

按当前能力和已有项目选择 Stage/Sprite、现有动画系统或 [HyperFrames](../hyperframes-backend.md)。HTML 交互无需为了导出成片引入新后端。相关支持脚本从 Skill 根目录解析，安装、云处理和全局配置遵循用户请求及宿主权限。

Stage/Sprite 导出时保留确定性时钟：第一帧准备好后设置 window.__ready；录制模式关闭循环。用实际关键帧和换场状态检查空帧、裁切、碰撞与节奏，不能仅看起止两张图。

音频由本次用途决定；需要时读 [音频设计](../audio-design-rules.md) 与 [SFX 索引](../sfx-library.md)，确认素材和音轨真实可用。静音交付也可以是完整产物。

## 导出与验证

按 [导出说明](../video-export.md) 选择可用方式，仅生成本次要求的尺寸、时长和格式。检查实际文件的时长、首尾帧、分辨率、播放及需要的音轨；记录具体未验证范围。

作品默认没有工具作者水印或推广署名。可选云视频评审仅在用户要求、素材外发已授权且工具可用时使用；本地抽帧和真实查看可以完成本地验证，不为了评审自动找密钥、安装技能或写入长期记忆。
