# v0.1.47-rc.1 release qualification

日期：2026-11-23。用户指定 Space `0.1.47-rc.1` 预发布；SDK 升级到 npm Registry `@kodax-ai/kodax@0.7.97-rc.1`（自 beta.4 的 beta.13，SDK Issue 433 / Space Issue 255），四个 workspace 与 lockfile 统一 Space 版本。稳定版保持 v0.1.46，不向正式版自动推送预发布。已发布的 beta.4（beta.13 构建）及更早 beta/alpha 记录保留为上一轮发布历史。

## 发布范围

- SDK `0.7.97-rc.1` 接入（Issue 255）：任务结束后不再残留"正在运行"的工具卡——扩展处理器内部发起的嵌套工具调用（如 `tool_call` 转发 `artifact_render`）不再单独生成 View 工具项，其进度显示在模型发起的卡片上；Run 进入终态时把残留 `running` / `awaiting_approval` 项结算掉；重开旧会话移除无结果且无对应 `tool_use` 的旧记录。这些调用仍经权限、沙箱与审批，审批卡按工具名与输入显示。
- 跟随 SDK rc.1 模型目录：灾备默认模型改为 Claude Sonnet 5.5、GPT-6.2 Sol、Qwen3.8 Max 与 MiMo v2.6 Pro（测试保持与 SDK 默认一致）；回退上下文上限覆盖 Claude Fable 5.2 / Opus 5 / Sonnet 5、GPT-6.x / 5.6 / 5.5（1.05M）、Qwen3.8 Flash、GLM-5.3-highspeed 与 DeepSeek V4.1 Flash；自定义 Provider 表单提示当前模型名。settled 工具组的状态芯片不再裁剪 tally、标签与统计（30rem 上限移除，仅工具名摘要按行宽截断）。
- F149 归档分区收敛：归档任务与项目共享侧栏底部一个 "Archived (N)" 分区——默认折叠、无归档时隐藏、折叠时其任务带注意力角标；归档任务按项目名分组，离开项目列表与 "+N more" picker（含打开中的任务），归档时提示去向；悬停归档任务/项目提供 Unarchive 与红色删除按钮（均先确认）；归档项目不再提供新建任务按钮；项目菜单的 Remove 使用同一垃圾桶图标。替代此前无标签、看似无效且把打开中/需注意的归档任务留在项目内的 "Show archived sessions" 开关。
- 对话展示：用户查询为紧凑浅蓝气泡、左对齐、带小发送者头像，与回复共用阅读栏（去掉独立标签行与粗强调条，复制/时间脚注悬停或聚焦显示）；用户停止的 Run 显示中性"已停止"提示（本地化文案、灰色时间线标记、副作用未知警告只出现一次），不再显示红色 "Run failed" 与 SDK 英文错误。"Return to newest messages" 按钮回到对话中线（弹出动画不再覆盖居中变换）。
- 当前 README、文档索引、Feature List、用户手册基线行随 rc.1 更新；应用内 `space_manual` 话题、v0.1.47 设计、F149 人工测试指引与能力台账已随功能提交对齐（归档分区、中性停止提示、结算工具组与模型目录）。SDK 自有 `kodax_manual` 不被覆盖。

## 验证与发布门

- 本地 Windows 完整源码检查：typecheck、lint（`--max-warnings 0`）、workspace 单测（desktop electron/renderer、ipc-schema）与 `npm run test:release`（含 `skills:check`、原生资源预热与 `scripts/test/*.test.mjs`）全部通过（2026-11-23）。
- 发布需同一 SHA 的四平台完整源码检查（ci.yml E2E 双分片 + build.yml 四平台 smoke、静态检查与门禁）、成品构建和成品消费验收。Mac arm64/Intel 在候选归档前通过 `codesign --verify --deep --strict`；Windows 打包 smoke 继续校验 SDK 原生资源哈希与内置 Skill 解包完整性。
- 最终 SHA、运行链接、平台结果与资产校验记录在发布后补记的验证文档（`v0.1.47-rc.1-release-verification.md`）。该记录未确认的项目不得以源码通过替代。

## 保留边界

- macOS ad-hoc 不等于 Developer ID 或公证，首次启动仍可能有 Gatekeeper 提示；通知/图标角标需要系统权限，macOS 仍手动下载 DMG 更新。Windows 安装器未签名。
- Issue 371 首次历史读取延迟仍未关闭，Issue 254（Run 期间历史翻页重复/乱序）推迟到下一大版本；SDK Repo-intelligence Host 真实诊断/预热等接缝沿用既有验收记录，不因本版重开或宣称消失。
- 外部账号、真实模型质量/计费、覆盖安装/断电、客户 Kylin/真实 Mac 权限设置仍需对应环境验收。
