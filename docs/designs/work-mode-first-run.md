# 首轮固定工作模式

用户决定：“应该只有新会话能选择……KodaX 和 Space 应该都是这样”。视觉选择 B（滑动分段）。

- 新的空会话可选择 Agent / Coding / 实验性 Script，默认 Coding；Host 保存确认后才更新选中态，保存期间禁止发送。
- 首次 Run 被接纳后固定模式。空闲、重启、恢复、清除当前窗口和已有历史的分支不能重新开放选择。
- 后端统一约束普通设置、带版本设置和单次 Run 参数；同值写入不视为切换。模型、权限仍按各自既有规则处理。
- Host 设置快照返回只读 workModeLocked。旧 Host 缺失此事实时，Space 禁止模式修改并提示升级，不猜测为空会话。
- Space 已开始会话显示只读图标、模式和锁定提示；Mock 不显示 AMA 假入口。帮助指向 /work-mode。
- CLI 单次执行参数中的 workMode 作为首次选择保留，不在执行后回滚；其他单次参数保持原恢复语义。
- 支持键盘选择、可见焦点与减少动态效果。

后端为新会话显式保存未锁定标记，在首次 Run 准入时永久锁定，并以完整 lineage 判定已有历史。旧版/导入会话缺少首轮状态时保守保持原模式，需要更换请新建会话；不依赖 Run 索引或当前可见消息数，不在启动时重写历史文件。

- KodaX：首轮设置、共享 Host、CLI one-shot、客户端设置及历史隔离共 28 项回归通过；另有旧快照不能抹除永久锁的存储回归通过。构建及源码类型检查通过。
- Space：Host 设置、旧 Host 拒绝、命令提示、键盘选择与导航竞态共 6 项测试通过；渲染器和主进程构建、类型检查通过。
- 桌面 E2E：新会话选择、已开始会话命令拒绝、跨客户端 CAS/运行中锁定/重载、Script 权限与停止恢复、权限快捷键独立性共 5 项通过。
- 2026-11-08 已切换到 npm 发布的 SDK `0.7.97-beta.3`，Root、Desktop 与 lockfile 使用同一精确版本。缺少锁定事实的旧 Host 仍返回升级提示。此次安装与桌面验收见 [beta.3 接入记录](../releases/kodax-beta3-space-adaptation.md)。
