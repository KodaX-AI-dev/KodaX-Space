## 真实模型样板与边界

使用本机现有 DeepSeek / deepseek-v4-flash，经 SDK provider 调用真实专家定义和对应方法，未提供工具；这验证专业文字样板，不等于完整 Agent 工具交付或用户账号验收。

| 专家 | 样板核验 | 证据 |
| --- | --- | --- |

| 用户研究 | 两位用户计为 2 个独立样本，同一人重复反馈不当成两个人；保留低置信、原话及未验证假设 | model-reuse-final.json |

| 会议纪要 | 未将周五上线写为获批；已确定行动与待确认事项分开，没有虚构通知或会前确认 | model-samples.json |
| 邮件编辑 | 保留争取周五与日期未确认，交付草稿，不声称已发送 | model-samples.json |

**仍然存在的质量限制**：非推理模式第一次/第二次样例曾出现文案补造功能、研究过度推断、会议编造“会前确认”以及排期调整计算错误；方法已经针对这些发现补充约束，但不能保证模型后续不会再犯。开启 high 推理后的文案、研究、会议样例改善；项目管理完整调整方案复测先因输出预算耗尽无正文，再在 90 秒处超时，未计为通过。该专家本轮通过的是更窄的可行性/排期样板，复杂调整方案仍需核对。没有通过切换方法暗中强制用户使用特定模型或推理强度。
