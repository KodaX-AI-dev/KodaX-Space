Its Linux full unit job then exposed a separate compatibility-probe race (`run.failed` count 0): the probe neither awaited subscription readiness nor waited for the independent event delivery before closing. This candidate also remains unpublished and is superseded; its successful package checks do not substitute for the final source SHA's gates.

The build now writes the root manifest's real version. Task listing follows the existing mock Session creation boundary, keeping local tasks local while preserving real Host errors. Two new unit cases failed before the change and pass afterward (six total in that module); the actual cross-Session failure was also reproduced in the Windows package. Startup fixture evaluations now wait for the first native window, with early page/error listeners preserved, to avoid evaluating Electron's replaceable bootstrap context. There is no generic retry or ignored error.

Seven source UI cases passed in one zero-retry run after these changes: Reference Agent management, cross-Session task isolation/cancellation audit, notification settings, startup overlay and the three update shutdown cases. Typecheck, lint and both review axes pass. Candidate `8c641497` was stopped unpublished so the final candidate can include these corrections; no previously published tag or release assets were overwritten.
