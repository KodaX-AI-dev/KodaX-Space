# v0.1.46-beta.4 release readiness

> Historical rc.5 qualification record. The current working tree retains the Space
> beta.4 package version and advances to published KodaX rc.6 for the Windows
> Runtime startup correction. The rc.5 scope and results below describe the earlier
> artifact; current rc.6 qualification is tracked in the
> [Runtime startup regression guide](../test-guides/ISSUE_RUNTIME_HISTORY_STARTUP_0.1.46_REGRESSION_GUIDE.md).

Date: 2026-09-14. Previous release: v0.1.46-beta.2 (published). v0.1.46-beta.3 is a
transitional release: its tag remains as history, but its GitHub release was withdrawn at
maintainer decision because it shipped the bundled Partner library without the rc.5/Issue 215
work and its CI required reruns for shared-runner Partner test flakes. beta.4 is being prepared
to carry both the Partner integration and the rc.5 alignment; it has not been published.

## Scope

- Restore ordinary Coder/Partner links to the existing system-browser path. Remove the
  Partner webview and its dedicated navigation policy while keeping saved source snapshots,
  local file previews, result cards, expert and connector functionality.
- Remove the Feishu network prerequisite from development startup. Expose explicit Settings
  component preparation, separate from account authorization, with pinned integrity checks
  and reuse after restart. Packaging still validates bundled resources.
- Persist changed connector authority even when another binding is removed, and handle both
  expert/connector navigation directions. The current library retains its frame; an older
  installed library uses a fresh frame/bridge for management navigation, clearing unsaved
  page edits while preserving installed packages and saved configuration.
- Pin the exact published KodaX `0.7.96-rc.5` in root/Desktop manifests and the lockfile,
  superseding rc.4. Every rc.4 capability requirement is retained (`sandboxRuntime:11`,
  `runtimeAutoModeGuardrail:6`, `sharedSessionSettings:2`, `providerCredentialBroker:2`,
  `effectiveConfig:1`, daemon `sessionCancellation:1` with durable frontier,
  `toolInvocation:1`).
- Fix Issue 215: pasted-image fallback validation through the optional SDK media validator —
  confirmed corrupt images are rejected with a recovery instruction instead of being re-sent
  to Providers as repeated upstream HTTP 400s; valid WebP survives normalization without its
  codec; older SDKs or an unavailable validator keep the existing fallback.
- Release checks exercise the actual packaged image decoder, including its Worker and WASM
  dependency, and verify repaired image files can be read again without changing original
  history.
- Keep the bundled-Partner browser suites and Feishu document-service probes green on shared
  CI runners: 3-5s Playwright action budgets and a ~500ms task poll became bounded,
  contention-tolerant waits (15s CI action budget, 10s CI task poll, verified change count
  awaited before the exact-count assert). Every assertion stays strict.
- Carry the beta.3 Partner-library bundling (PR #5) forward: bundled expert/connector
  directory on fresh installs, trusted-host session bindings, serialized connector record
  reads, macOS esbuild deduplication, and the packaging size fixes. See
  [v0.1.46-beta.3 readiness](v0.1.46-beta.3-release-readiness.md) and
  [partner docs](../partner/README.md).
- Synchronize workspace versions, changelog (including the beta.3 withdrawal record),
  READMEs, capability ledger, product/architecture/usage docs, user manual, feature list,
  `docs/features/v0.1.46.md`, and kodax_manual.

## Qualification

Checks target the combined beta.4 repair; earlier-version checks are not acceptance of
this patch.

- `npm run typecheck`, `npm run lint` and `npm run build:smoke` passed locally on Windows.
- Final `npm test` passed: release scripts 83 passed / 7 skipped, Desktop 3,732 passed /
  13 skipped, IPC schema 362 passed / 0 skipped; 4,177 passed, 20 explicit platform skips,
  zero failures overall. Playwright Chromium was installed, so browser-fixture checks ran.
- Isolated Electron acceptance passed all 22 distinct scenarios across `partner-mode`,
  `partner-layout`, `partner-bundled`, `artifact-html-runtime`, `artifact-file-preview`,
  `markdown-file-actions` and `session-send-retry`. The file suite used synthetic PDF
  (three pages), PNG, GIF, TXT, DOCX, XLSX, PPTX and WAV samples; PDF keyboard paging and
  project HTML modules/assets/storage/workers were exercised without Downloads skips.
- Independent Standards and Spec reviews found an oversized new UI function and a
  Settings/active-session Feishu installation race. Both were fixed and re-reviewed.
  The race regression verifies one preparation and independent waiter cancellation;
  additional independent probes covered both joining orders and either waiter cancelling.
- Initial full-suite failures exposed Windows symlink permissions, locale/shortcut assumptions,
  an oversized browser fixture, a moved test path and obsolete UI text assertions. Directory
  link checks now run through Windows junctions; only explicit unsupported file-link/POSIX
  permission cases skip. Interaction assertions remain strict.
- `node scripts/pack.mjs --win` passed with the exact Registry-verified rc.5 package.
  Setup is 172.97 MiB; Portable is 172.77 MiB (both below 200 MiB). Package checks verified
  the bundled Partner library, Feishu archive, SDK/native dependencies, real image decoder
  (valid PNG and corrupt JPEG), Worker/WASM, Runtime and constructed-handler execution.
  Packaged boot and two complete exits passed; Session history restored successfully.

## Remaining boundaries

Pure configuration-type extension commands remain CLI-owner-only. Partner Coder sharing of
experts/connectors remains a follow-up from PR #5. Real external-account acceptance and
automatic library replacement for the bundled Partner library remain open items from the
beta.3 readiness record. FEATURE_275 long-term guarantees are unchanged from beta.2.
