## Pre-tag repair history

main carried red CI before this release: `build.yml` had failed on every push since 2026-11-19 and both workflows failed on `ee64127b`, the immediate parent of the release-preparation commits. Every failure was reproduced or attributed locally before any fix was pushed.

- **Stale test (deterministic, 3/3 on both ubuntu E2E shards of two runs)**: `workspace-sidebar-density.spec.ts` selected the globally first session row; since `0ed14beb` sorts newest projects first, that row belongs to the newest (non-git) project, selecting it switches the workspace away from the seeded git project, and the right-sidebar Changes section never lists `workspace-navigation.tsx`. Fixed by selecting a session of the seeded git project through its project block and threading the session id (`fb46a699`); verified green locally and on both ubuntu shards afterwards.
- **Linux zombie race (ubuntu smoke, `fb46a699` run)**: `fixture-daemon-cleanup` asserted grandchild death immediately after the wrapper's group kill returned; an orphaned descendant still answers `kill(pid, 0)` until init reaps it. Fixed with a bounded wait-to-die (`fb46a699`).
- **Cold Runtime worker boot budget (macOS smoke)**: the published-worker probe exceeded 30 s on both macOS jobs of `ee64127b`, passed at 60 s, then exceeded 60 s on later loaded-Intel attempts. Raised to 60 s (`fb46a699`) and given one retry on the timeout error only (`c4837b82`), with the test budget covering two probes.
- **Loaded-Intel frame-paced browser checks**: across 2026-11-21 attempts the degraded `macos-15-intel` pool failed a different frame-paced check each run — the live-return settle of `conversationHistoryNavigation` (three stalls at 45 s/90 s with zero progress), and the `conversationTranscriptWindow` tail-gap/resync-coverage single-frame samples. Fixed by forcing one live write after the live return (a follow-write pins the bottom, mirroring the test's own second half) and polling the tail-gap and row-coverage predicates bounded (`e00682b9`). No assertion was deleted; a wrongly re-following reader or a spacer still fails. Three failed-job reruns on intermediate SHAs are attributed to this pool degradation, matching the Mac Intel flake precedent recorded for beta.2; the final SHA needed no rerun.
