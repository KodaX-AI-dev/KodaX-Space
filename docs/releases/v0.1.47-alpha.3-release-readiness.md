# v0.1.47-alpha.3 release readiness

日期：2026-10-20。目标：Space `0.1.47-alpha.3` 预发布；用户已确认版本。准备阶段记录；tag、推送与 GitHub Release 状态见文末验证记录。

## 发布范围

- 精确锁定正式 Registry `@kodax-ai/kodax@0.7.97-alpha.9`（经由 alpha.7、alpha.8 推进）。不携带 sibling SDK 源码，不补丁依赖字节；发布依赖 gate 按 tarball SRI 与五个 native 目标逐字节校验。
- Issue 222 恢复：启动前发现共享 Session 存储的真实 Host（含启动竞争中获胜的 owner）；复用兼容 Host，经验证的空闲旧 Host 经 SDK 托管关闭替换；新 Host 请求 interactive 生命周期；保护活动工作并持续重试直到所选历史可恢复。既有 Host 退出或连接/就绪暂时超时后自动改用 SDK guarded startup，永久性不兼容不再重试。
- SDK alpha.9 的 Session 准入 CRC/EIO 修复随包接入：Run 准入读 canonical 身份元数据，已初始化 Actor 控制器在 durable owner fence 之后沿用既有准入；其他客户端 `protected` 退出分类保持。
- 收口 2026-10-18 对齐审计指出的共享 Host 迁移缺口：Workflow 启动经 Host owner 与 Host 管理目录；权限请求携带 SDK 完整定稿 plan（受 daemon 帧上限约束，不做缩短预览）且在批量审批中单独评审；MCP 面板经共享 Runtime 读取服务器状态、共享 Host 下拒绝单服务器 stop；Memory 提案增加 revision 守卫与 curate/pack 能力上报；host-image 模块经分页 Host 读取与 SHA-256 校验展示工具图片附件；内置 Skill 路径经打包资源在共享 Host 内注册；Run 投影暴露类型化 terminal 事实。
- 保留会话观察者跨排队/中断准入与 canonical view 交接；SDK 确认 terminal Stop 后释放匹配的本地 Run 准入提示；被动重连、完整退出与持久退出恢复保持 Host profile。
- 同步 README、文档索引、PRD/HLD/DD、用户手册、能力台账、feature list、版本设计与 in-app 手册至 alpha.3 / SDK alpha.9 基线；记录 alpha.7 上游变更清单、输入授权与 Host 领域审计、内置 Skill Host 探针、Artifact 发布路径审计；task-companion 设计探索作为未实施材料入库。

## 已知边界

- 真实外部模型、外部账号与 macOS/Linux 的 process acceptance 仍按既有清单处理；本轮本地验收为 Windows。
- 可选 `@kodax-ai/artifacts` 独立包仍未在 npm 发布；Artifact 能力继续经主包四个子路径与内置 worker 提供，不宣称新的独立包接入。
- task-companion/companion-dog 设计与 space-ui-exploration 均为未实施探索材料，不代表当前产品 UI。
- 安装包仍未签名；macOS 手动 DMG 更新；alpha.3 不替代默认稳定下载，不覆盖既有预发布版资产。
