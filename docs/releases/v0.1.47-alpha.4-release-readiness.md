# v0.1.47-alpha.4 release readiness

日期：2026-11-05 准备。目标：Space `0.1.47-alpha.4` 预发布；用户已确认版本。tag、推送与 GitHub Release 状态见文末验证记录。

## 发布范围

- 精确锁定正式 Registry `@kodax-ai/kodax@0.7.97-alpha.11`（经由 alpha.10 推进）。不携带 sibling SDK 源码，不补丁依赖字节；发布依赖 gate 按 tarball SRI 与 native 目标逐字节校验。
- Host 工作模式：首条 Coder 输入前可选 Agent/Coding/实验性 Script，设置确认前阻止发送，`/work-mode` 与 Host 设置同边界；SDK alpha.11 带来 Host 流式 token 估算、显式保存 tool-original 读取、结构化任务报告与非交互提问结果。
- 客户反馈修复（Issues 236-238）：同一修订的历史页连续累积、不再替换丢失较新回答，view 进入历史恢复阅读锚点，底部按钮回到真实最新消息；任务/项目重命名 Enter 或失焦只提交一次、Esc 取消、IME 选词不提前提交、保存失败保留原名并提示；用户问题带常驻发送者标签、淡蓝底色与左侧色条。
- 此前积累的源内修复随本版首次安装包交付：冷启动长历史补读的 React 185、退出恢复评估不重写历史 unknown、在线 peer 保护 Host 时保留已验证个人清理、排队输入凭据租约在 Main 重建后独立恢复、经独立可信 Host extension 启用已发布 Artifact 工具、软件更新改手动检查并拒绝候选版本、银河麒麟 Linux 原生标题栏窗口控制。
- 内置 Skill 打磨：自然语言选择与任务规模交付，去除无条件设计变体与重复审批。

## 已知边界

- 真实外部模型、外部账号与 macOS/Linux 的 process acceptance 仍按既有清单处理；本轮本地验收为 Windows。
- 可选 `@kodax-ai/artifacts` 独立包仍未在 npm 发布；Artifact 能力继续经主包子路径与内置 worker 提供。
- Partner 的 Agent/profile 组合仍是 SDK 后续工作；统一 Host 单连接迁移未接受、未实施。
- 安装包仍未签名；macOS 手动 DMG 更新；alpha.4 不替代默认稳定下载，不覆盖既有预发布版资产。
