# v0.1.47-alpha.4 release qualification

日期：2026-11-04。用户指定 Space `0.1.47-alpha.4` 预发布；精确依赖 npm Registry `@kodax-ai/kodax@0.7.97-beta.1`，四个 workspace 与 lockfile 统一 Space 版本。稳定版保持 v0.1.46，不向正式版自动推送 alpha。

## 发布范围

- SDK alpha.9 → beta.1 的接入与 Space 补审修复，见 [beta.1 接入](kodax-0.7.97-beta.1-integration.md)、[完整验收](kodax-beta1-full-acceptance.md)与[Claude 补审](kodax-beta1-claude-followup.md)。前几轮各自使用旧版本号的记录保持原始证据，不等同于本轮发布回执。
- Coder/Partner 同一共享 Host；Coder 默认 Coding，可独立选择 Agent / 实验性 Script，Partner 使用 Agent 注入和消费时业务绑定，正常 shell/write/子 Agent 能力保留。Host 配置、输入、Session 与 statistics 是事实来源。
- Provider 与稳定客户端凭据使用权限受限的 auth.json；保留来源选择、账号身份、CAS、迁移、原授权及恢复边界，不依赖 Keychain。
- 手动检查/下载/安装更新、Linux 窗口按钮、React 185、历史双向翻页、结构化中性任务报告、内置 Skill/Host 注册及错误分类等先前修复随本版交付。
- Issue 236：macOS 使用 ad-hoc 签名满足 Electron 42 通知要求；原生 show/failed/未确认结果区分，设置页提供显式测试，授权后恢复原有角标计数（包括迟到授权）。保留通知默认关闭、后台且超过一分钟的实时任务等原触发边界。
- 当前 README、文档索引、PRD/HLD/DD、能力/凭据台账、用户手册、版本设计与应用内组合手册同步。SDK 自有 `kodax_manual` 不被覆盖；产品使用 `space_manual` 扩展。

## 验证与发布门

- 修复层完整本地 `npm test`：4,667 项，4,647 通过、20 条件跳过、0 失败。typecheck、lint、build 通过。通知原生失败/成功/超时/迟到授权、点击定位与角标权限恢复有定向回归；设置 UI→IPC 和手动更新交互通过。
- 两轴补审：Standards 硬违反/可行动判断题均 0；Spec 最终新增 finding 0。迟到授权与两份手册是评审中发现并闭环的遗漏。
- 发布需同一 SHA 的四平台完整源码检查、成品构建和成品消费验收。Mac arm64/Intel 必须在候选归档前通过 `codesign --verify --deep --strict`；Resources 不重签，SDK 原生资源哈希门继续保留。
- 发布成品新增通知设置验收，模拟系统 show/failed 以验证 UI→IPC→Main；这不能代替真实 OS 授权、横幅、声音或 Focus 检查。详见 [Issue 236 指引](../test-guides/ISSUE_236_0.1.47-alpha.4_REGRESSION_GUIDE.md)。
- 最终 SHA、运行链接、平台结果与资产校验记录在 [本版发布验证](v0.1.47-alpha.4-release-verification.md)。该记录未确认的项目不得以源码通过替代。

## 保留边界

- macOS ad-hoc 不等于 Developer ID 或公证，首次启动仍可能有 Gatekeeper 提示；通知/图标角标需要系统权限，macOS 仍手动下载 DMG 更新。Windows 安装器未签名。
- SDK Repo-intelligence Host 真实诊断/预热、integration writer 短暂占用恢复继续见 [SDK 交接](kodax-beta1-repointel-host-handoff.md)。队列持久接缝、promotion-view、原子 Partner 准入及共享 Host Workflow 管理限制沿用 [完整验收](kodax-beta1-full-acceptance.md)及[修复记录](kodax-beta1-space-fixes.md)。
- Issue 371 首次历史读取延迟仍未关闭，Host ready 不等于历史加载完成。不因升级宣称所有恢复性能或智能质量问题已解决。
- 外部账号、真实模型质量/计费、覆盖安装/断电、客户 Kylin/真实 Mac 权限设置仍需对应环境验收；Windows 本地或 CI 模拟通知不能替代。
